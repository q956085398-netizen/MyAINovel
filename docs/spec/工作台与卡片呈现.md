# 工作台、卡片与设置呈现

> **布局裁决（2026-09-19）**：正式方向为「B 编辑部案头主框架＋A 项目信息区＋C 沉浸书写页」。B 的窄轨侧栏负责日常管理页；A 的当前项目、继续工作与真实待办进入可展开项目信息区；进入正文后切换为 C 的低干扰布局。三套预览不是让实现者任选其一，也不得直接照搬某一版。

> 2026-09-19 用户逐项确认。本文补充并在冲突处取代 [个性化设置](./个性化设置.md) 与 [视觉系统](./视觉系统.md) 中关于设置入口、卡片布局和侧栏结构的旧决定。数据原则仍以 ADR 0002 为准。

## 一、目标

- 用户在列表页就能读完保存的内容，不为阅读摘要反复打开弹窗；
- 尚在发酵的内容始终回到视野，不沉入长列表；
- 主导航、上下文和工具各有稳定位置；
- 设置增多后仍只有一层分类，不形成设置套设置；
- 视觉变化不改变 Markdown/YAML 创作数据。

## 二、内容表面

### 2.1 完整内容卡

- 所有内容型卡片展示全部已填写字段和正文；不自动截断、不单行省略；
- 卡片没有内部滚动条，页面负责滚动；
- 用户可主动收起单卡，收起状态存应用状态；搜索命中隐藏内容时自动展开；
- 点击卡片打开右侧宽详情面板编辑；章节、拆书稿、大纲等长文进入完整编辑器；
- 空字段不渲染，也不显示“待补全”。

### 2.2 排布规则

| 内容 | 默认排布 | 次序纪律 |
|---|---|---|
| 灵感 | 自适应卡片墙 | 按筛选/排序；待打磨在顶部独立区 |
| 人物、组织、地图、地域 | 两列档案卡 | 稳定行序，不用瀑布流制造阅读顺序歧义 |
| 桥段、单元 | 一至两列编号顺序流 | 人工叙事次序必须清楚 |
| 搜索结果 | 紧凑列表 | 命中片段可展开 |
| 章节总览 | 卡片网格 | 只显示资料与本章意图，不显示整章正文 |

卡片正文维持适合中文阅读的行宽；不允许单卡横跨整个宽屏后形成超长行。

### 2.3 待打磨便笺

- 任意内容对象可切为「待打磨」；
- 待打磨对象以便笺形态出现在所属页面顶部，显示数量与完整内容；
- 「整理完成」解除状态，回到原类别和原排序位置；
- 无待打磨对象时整个区域消失；
- 便笺可以有轻纸感、小色签或夹角，但不用仿真泛黄、厚阴影或随机旋转；
- 待打磨是内容状态，应随对象文件保存；卡片收起、页面视图等仅为应用状态。

**数据契约（工单 #64 / T03 落地）**：状态＝对象自身 frontmatter 的布尔键
「待打磨: true」（灵感卡与五类构思笔记同构，任何同构 md 文件通用）。
进出只动这一个键：文件名、所在目录（类别）与正文一概不动，未知键原样
保留——原类别与原排序位置从未变过，「恢复」因此是无操作而不是重排，
也不存在完成时间可供排序（键一删即净）。切换是状态操作不是内容编辑：
写盘后把文件修改时间复原，mtime 排序的列表（灵感墙）不因进出待打磨被
顶到最前；便笺中的内容编辑照常更新 mtime。只有布尔 true 算待打磨：旧
内容无键、手写 false 或空值都按普通内容处理，且不认识的值不改动。便笺
区只是读模型过滤（`pending` 字段由扫描派生），不产生第二份内容或便笺
库；在便笺中编辑走对象正常的保存路径，frontmatter 以现有文件为底合并，
状态键自动存活。v1 覆盖灵感卡与构思笔记两类；桥段、地图等实体随后续
工单接入同一机制。

## 三、全局侧栏

```text
工笔
拆书
灵感库
构思
书写

当前库 / 当前项目
继续上次工作
当前板块待处理 3
  · 标题一
  · 标题二

AI 助手
设置
```

- 主板块在上，AI 与设置固定在下；
- 中部最多三块动态信息，不堆统计仪表；
- 待处理项随板块变化，并给 1～3 个可直达的真实标题；
- 今日字数继续留在书写页；不增加连续天数、热力图和效率排名。

## 四、独立设置页

| 标签 | 内容 |
|---|---|
| 外观 | 浅色/深色/跟随系统、三套配色、编辑器背景 |
| 编辑器 | 字体、字号、行距、对齐、首行缩进、自动保存、章前缀、写作行为 |
| AI | 供应商、模型、助手预设、上下文与隐私说明 |
| 库与数据 | 当前库位置、更改/新建、索引重建、备份入口 |

- 设置使用主内容区域，不再挤进纵向滚动弹窗；
- 只允许一层标签；高级供应商参数可在 AI 页折叠，不再打开另一套设置弹窗；
- 导出、发布、封面等对象动作不进入设置。

## 五、编辑器头部

- 第一层只放返回、标题、保存状态和一个主动作；拆书页主动作是「开下一章」；
- 插入块合并为「插入」菜单；
- AI 命令合并为「AI」菜单；
- 桥段标注等选区动作只在选区成立时出现；
- 排版工具栏默认折叠，设置页保留完整入口；
- 自动保存成功时显示状态，不长期占用一个置灰的保存按钮；`Ctrl+S` 继续立即保存。

## 六、主题与配色

主题明暗与配色预设是两个维度。三套预设均提供浅/深 token：

1. **朱砂纸墨**：暖米白、墨色、朱砂强调；
2. **竹青松烟**：灰青绿、淡纸色、低饱和竹青强调；
3. **靛青月白**：冷月白、深靛灰、克制靛蓝强调。

配色影响界面 chrome、表面、边线、侧栏与强调色；编辑器背景继续独立，切换配色不得改掉用户选择的宣纸、羊皮或自定义图片。

## 七、验收

- 只有一张内容卡时，正文仍保持可读行宽，不形成横向长条；
- 卡片页无需点击即可读完除章节正文外的对象内容；
- 待打磨卡能从任意类别进入顶部区域，再无损返回；
- 侧栏中部显示真实内容标题，底部设置位置稳定；
- 设置页不出现二级标签；
- 编辑器常驻头部不再同时出现插入块、AI 命令和完整排版三行；
- 三套配色在浅/深模式下均满足文字与交互状态对比度。
