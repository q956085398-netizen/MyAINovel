# 拆书 yaml schema 定稿

> 工单 #13 决议。依赖已就位：#10（词表——类型/解法是自由字符串，词表只提示不校验）、#11（编辑器边界——章梗概在正文、章节拍不做、v1 无章列表）。本文件描述的现状即 v1 实现现状（`book_file.rs`、`trope.rs`），字段与规则以此为准。
> **v2 修订（工单 #30/ADR 0006，2026-09-13）**：书级四项（书名/成绩/简介/金手指）已上纸面为 md 书档块，yaml 书级键**废止**（存量一次性迁移，见 [拆书保存与模板.md](./拆书保存与模板.md) §五）；yaml 收缩为桥段标注载体＋章前缀兼容键＋未知自由键。

## 总形态

一书 = 正文 `.md` ＋**主文件同名** `.yaml`（同目录、同名换扩展名）：

- 根目录散文件：`书名.md` ＋ `书名.yaml`
- 一书一文件夹：`《书名》/拆书.md` ＋ `《书名》/拆书.yaml`（新建拆书固定此布局，设计共识 §三）

**懒生成**：yaml 不存在＝这本书还没做过结构化标注（浏览/搜索照常）；首次「桥段标注」时才落盘（v2 起「书级资料」已废——书名/成绩/简介/金手指在 md 书档块里，不进 yaml）。无索引配合（工单 #12）：跨书检索永远现扫盘，不依赖 yaml 存在与否。

**章列表不进 yaml**（#11 决议）：章锚点（序数/标题/行号）每次打开从正文现算，yaml 不存章标题——不存在「手改标题行后 yaml 与正文谁对」的标题同步问题；章梗概是正文自由文本。

## 字段表

| 键 | 层级 | 形态 | 纪律必填 | 说明 |
|---|---|---|---|---|
| 章前缀 | 书级 | 字符串，含 `{n}` 占位 | | **兼容保留**（v2）：历史自定义值继续优先生效；全局设置作缺省（[拆书保存与模板.md](./拆书保存与模板.md) §六），新建书不再落此键；空值由应用回退默认（单一事实源在 Rust 侧） |
| 书名/成绩/简介/金手指 | 书级 | — | | **已废止**（ADR 0006）：存量一次性迁入 md 书档块后从 yaml 删除；书库列表取数改走 md 书档 |
| （其他任意键） | 书级 | 任意 | | 自由扩展位：手补键原样保留、顺序不变（读-合-写，ADR 0004） |
| 桥段 | 书级 | 列表 | | 整表由应用受管（见下） |

桥段条目（列表元素）：

| 键 | 形态 | 必填 | 说明 |
|---|---|---|---|
| 起 | 正整数 | ✔ | 起始章的序数（第几个章标题，1 起），与前缀模板无关 |
| 止 | 正整数 | ✔ | ≥ 起 |
| 类型 | 字符串列表 | ✔（≥1） | 自由字符串，词表只提示不校验（#10） |
| 解法 | 字符串 | | 单值；空串/全空白按无处理，不落键 |

**桥段条目内不认未知键**：桥段列表是应用的结构化领地（跨书筛选依赖其形状），保存时整表重写，手补进条目里的键会丢——要挂私货挂书级自由键。与书级「未知键保留」的分界即「人机共管 vs 应用受管」。

**桥段条目不加「一句点评」「关联灵感卡 id」**：点评属于正文 callout，双处记同义内容必漂移；与灵感卡的关联由卡片侧「关联」自由文本单边持有（反向硬 id 是双源记账，#4 构思数据模型若将来需要再议）。

## 序数锚与漂移

- 起止用**序数**而非章号：中文数字章号无法可靠转数值，序数对任意前缀模板成立。
- 在已标注区域之前**插入/删除章**会使既有桥段的序数整体漂移——v1 接受：拆书以追加为主（Ctrl+Enter 开下一章），桥段面板每次打开都按当前正文现算展示，漂移可见可手改。升级路径（痛点真出现再做）：锚改存「序数＋起章标题」双保险，保存时不匹配即提示重对。
- 用户手改章标题行：无影响（yaml 不存标题）。

## 损坏与冲突

- yaml 解析失败：读取**显式报错**——编辑器/面板先警告「保存会整文件覆盖」，书库列表降级为缺省不拖垮扫描（现状）。
- 外部并发改写：桥段保存、书级键迁移均为「读-合-写」（未知键保留），按 ADR 0004 视为已满足冲突安全；正文保存走版本指纹闸（工单 #12 本次落地）。
- 写入原子性：全部走同目录临时文件＋rename（ADR 0004）。

## 完整示例

`《大魏读书人》/拆书.yaml`（v2：书级四键已废，只剩兼容与受管键）：

```yaml
章前缀: 第{n}章        # 兼容键：历史书才有；新书走全局设置
我的私货: 手补的任意键，应用原样保留
桥段:
- 起: 3
  止: 6
  类型:
  - 掉马甲
  - 打脸
  解法: 扫地僧式深藏不露
- 起: 12
  止: 15
  类型:
  - 修罗场
```

同目录 `拆书.md` 的对应正文形态（v2：稿顶书档块＋章梗概＝章标题后第一段，#11）：

```markdown
> [!书档]
> 书名：大魏读书人
> 成绩：24000
> 简介：寒门学子偶得文章圣殿，以才学步步登天
> 金手指：读书入记忆宫殿，读得越多气运越厚

第3章 诗会惊座
诗会上被人轻视；主角随口成诗；座中变色；身份初露端倪。
正文……

> [!出场人物]
> 陈平安、李翰林、吴先生
> 李翰林首次登场，负责当捧哏踩主角。
```
