## Parent

#76 整体验收修复与终验；对应用户故事 21、23–29，以及 A3 的期待线部分。

## What to build

期待感和目标两页中的期待线都可进入独立待打磨状态，顶部完整便笺突出需要继续思考的内容，整理完成后回到原类别、档位和次序。

## Acceptance criteria

- [ ] 期待感与目标共用现有期待线模型及状态合同，两页均可进入、编辑、退出待打磨并持久重读。
- [ ] 原 YAML 条目使用独立布尔键“待打磨”；无键和 false 为普通对象，退出移除键，旧文件无需迁移。
- [ ] 顶部完整便笺展示名称、类别、档位、状态、埋设与兑现及说明，保留原有有效操作；默认网格或筛选不隐藏待打磨对象。
- [ ] 进入、退出与编辑不擅自改变类别、短中长档位、兑现状态机、锚点及条目次序；空区消失，整理完成恢复原来的展示归属。
- [ ] 只改原目标条目，未知字段及同表其他条目保留，不建立便笺副本；搜索与看板共用权威数据。
- [ ] 外部修改、损坏 YAML、陈旧或歧义目标拒绝不安全覆盖，沿用原子写和现有冲突安全约定。
- [ ] 临时库回归分别验证期待感和目标的完整往返、旧格式、未知字段、外部变更和拒写；页面流程验证两页顶部便笺、搜索定位、空区及原档位恢复。

## Blocked by

None (can start immediately). 不人为依赖伏笔工单；共用模块的改动需要协调，但不是功能启动门槛。
