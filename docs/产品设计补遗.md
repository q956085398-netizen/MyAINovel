# 工笔产品设计补遗（2026-09-19）

> 本文记录 2026-09-19 `grill-with-docs` 多轮拷问后的共同决议，补充并在冲突处取代 [设计共识](./设计共识.md) 与既有专项规格。它只定产品与数据方向，不表示应用代码已经实现。

## 一、为什么重新打开设计

现有应用已经具备拆书、灵感、构思、书写与 AI 的完整骨架，但使用反馈暴露出三类问题：

1. 设置、编辑器头部、侧栏与卡片页面的信息层级不够清楚；
2. 方法论的宏观骨架已经存在，读者遐想、力量体系、地图等关键思考界面仍不够可见或可用；
3. 人物、组织、地图与地域之间的关系模型过薄，导致卡片和画布只能展示少量摘要。

本轮沿用根目录 `readme` 的四道设计闸：**直观、便捷、可见度高、美观**。理论进入产品时继续遵守渐进原则：能自由写的先自由写，只有需要关联、筛选、派生视图或可靠跳转的内容才结构化。

## 二、信息架构

### 2.1 全局侧栏

- 上部：拆书｜灵感库｜构思｜书写四个主板块；
- 中部：当前库/项目、「继续上次工作」、随板块变化的一项待处理内容；
- 待处理内容显示总数与 1～3 个真实标题，而非只有数字；
- 下部：AI 助手与设置；设置固定在底部；
- 今日字数、连续天数、热力图等不进入全局侧栏。

### 2.2 独立设置页

旧滚动弹窗被独立设置页取代，只保留一级标签：

1. **外观**：明暗模式、配色预设、编辑器背景；
2. **编辑器**：排版、自动保存、章前缀、写作行为；
3. **AI**：供应商、模型、AI 助手预设、上下文与隐私说明；
4. **库与数据**：库位置、索引重建、备份相关入口。

导出与发布仍属于具体作品，不进入设置。

### 2.3 构思首页

构思页新增轻量首页，汇总创意/大纲、读者遐想、金手指/力量体系、人物与组织、地图、矛盾/桥段/排布和尚未解决的问题。已有内容给摘要，尚未开始的方向最多给一个可关闭的引导问题；不显示完成百分比、红色缺项或强制顺序。

## 三、卡片、便笺与阅读

### 3.1 默认直接读完

- 内容型卡片默认展示全部已填写字段与正文，不再用横跨窗口的一行条卡；
- 页面整体滚动，卡片内部不设滚动条；
- 用户可主动收起单卡，收起状态只存应用状态；搜索命中时自动展开；
- 点击卡片主要用于编辑，默认打开右侧宽详情面板；章节、拆书稿、大纲等长文继续进入完整编辑器；
- 章节总览不展示整章正文，只展示章节资料与本章意图。

### 3.2 页面各用合适排布

- 灵感库：自适应卡片墙；
- 人物、组织、地图、地域：两列完整档案卡；
- 桥段、单元：一至两列编号顺序流，不用会打乱次序的瀑布流；
- 搜索结果：紧凑列表，正文命中片段可展开。

### 3.3 待打磨与便笺

任何内容卡片都可被作者标记为「待打磨」。进入该状态后，它以便笺形态移动到所属页面顶部的「待打磨」区；区域显示数量和完整内容，没有内容时整体消失。「整理完成」只解除待打磨状态，卡片回到原类别与原排序位置。

便笺表达内容仍在发酵，不是任意换皮。完整规则见 [工作台与卡片呈现](./spec/工作台与卡片呈现.md)。

## 四、编辑器动作层级

拆书/书写编辑器顶栏只保留返回、标题、保存状态和一个靠近当前任务的主动作。插入块收进「插入」菜单，AI 命令收进「AI」菜单，桥段标注等选区动作只在有合适上下文时出现；排版栏默认折叠，完整设置在设置页。自动保存成功时显示状态，不用一个长期置灰的保存按钮占位。

## 五、理论进入构思

理论采用三层落法：

1. **结构化数据**：确实需要关联、筛选和派生视图的内容；
2. **可删引导**：力量体系、情绪设计等思考过程；
3. **技法卡与方法视角**：流派化、非普适的方法，不成为硬校验。

具体补足：

- 「类型圈」对用户显示为 **读者遐想（类型圈）**，空态提示题材期待、刻板印象与本书独有爽点；
- 桥段增加可选、可重复的「类型 → 解法」配对；
- 力量体系仍属于世界观，但获得等级边界、力量来源、升级条件、代价限制、主角例外、剧情展示与下一阶段期待的可删模板；
- 情绪设计可在桥段中折叠提示“前置欲望/理由、递进触发、兑现画面”，不逐章评分；
- `理论基础/` 保持设计来源；应用复用技法卡和上下文方法提示，不新造理论板块。

覆盖情况见 [理论覆盖矩阵](./理论覆盖矩阵.md)。

## 六、人物、组织与社会关系

- 组织升格为书内实体，一组织一文件；灵感库组织卡只经转生单向接通；
- 人物摘要可选字段：图片、一句话身份、组织、别名、年龄/年龄感、性别、性格关键词、当前目标、能力/优势、弱点/代价、人物秘密；生平、外形、口吻、人物弧光等继续写自由正文；
- 人物可同时属于多个组织，每条组织关系记录身份/职位、当前/前任、公开/秘密与关系类型；
- 构思入口改为「人物与组织」，内含人物、组织、关系画布；
- 关系画布支持人物—人物、人物—组织、组织—组织，人物节点为圆形、组织节点为方形或圆角矩形；
- 节点默认显示图片/图标、姓名、一句话身份和组织摘要；完整档案在右侧面板；
- 画布允许拖拽并保存坐标，普通自动整理保留已固定节点，「全部重新布局」重排全部且可撤销。

社会网唯一来源为 `构思/关系.yaml`，见 [ADR 0008](./adr/0008-first-class-maps-regions-and-social-graphs.md) 与 [人物关系画布](./spec/人物关系画布.md)。

## 七、地图、地域与地图画布

- **地图**是整体故事空间；一个项目可有多张地图；
- **地域**是地图内部区域；地域需要进一步细化时可展开为另一张地图；
- 地图记录整体阶段目标、中心矛盾、核心秘密、当地主线摘要、进入/离开条件与关联对象；
- 地域记录局部功能、氛围、人物、组织、矛盾、隐秘、单元、伏笔和时代；
- 构思增加「地图」入口，内部为全貌｜地域｜转场｜历史；
- 地图转场处理大空间更换的叙事承接；地域连接只处理相邻、通道、往返等局部关系；
- 千丝万线、莲花、千层饼是同一数据上的观察方式，不是互斥模板；
- 地图画布分全书地图和单张地图两级，可叠加人物、组织和情节信息；
- 画布由实体与关系派生，可拖拽、固定、自动整理、创建关系与转场，但不是自由白板；
- 每张地图可选一张附件图片作背景并摆放地域节点，不提供绘图工具。

地图网唯一来源为 `构思/地图结构.yaml`。完整规格见 [地图与地域](./spec/地图与地域.md)。

## 八、AI 助手

- AI 面板保留会话选择、新建、删除与收起；设置按钮移入总设置；
- 新概念为 **AI 助手预设**，与书内人物、人物对话和固定 AI 命令严格分开；
- 内置预设：通用助手、拆书教练、构思搭档、文字编辑；可复制，不可直接修改或删除；
- 用户预设包含名称、说明、图标、识别色、系统提示、可选供应商/模型覆盖及默认标记；
- 每个会话固定一个预设，切换时复制上下文为新会话；
- 预设只影响普通对话，不覆盖润色、排布体检等固定命令；
- AI 设置明确展示什么操作会把什么材料发送给供应商。

完整规格见 [AI 助手预设](./spec/AI助手预设.md)。

## 九、书写增强

保留“写作本身优先”的边界，增加：

- 章节卡片总览：章号、标题、状态、字数、摘要/本章意图；第一版只浏览和进入章节，不拖拽改序；
- 写作快捷便笺：复用灵感速记，自动关联当前项目/章节并存为待打磨；不另建便笺库；
- `Ctrl+K` 全局本地搜索：书、章节、人物、组织、地图、地域、单元、桥段、伏笔与灵感；
- 光标拆章：用户显式触发，预览后把光标后的正文移入新章；
- 主动校对：中文标点/成对符号、重复字词、自定义易错词、人名地名与专名一致性；只列问题和跳转，不自动改；
- 版本 diff 仍为后续信号项；明确不做专注计时、连续写作和热力图。

完整规格见 [书写增强](./spec/书写增强.md)。

## 十、视觉方向

沿用“现代通透”的结构刻度，但从“统一条卡”升级为内容驱动的表面语言。三套全局配色均支持浅色/深色：

- 朱砂纸墨；
- 竹青松烟；
- 靛青月白。

配色影响侧栏、界面表面、边线和强调色；编辑器背景保持独立。静态预览位于 `app/prototypes/gongbi-design-preview.html`，只用于视觉确认，不是生产代码。

### 10.1 已确认的布局组合

2026-09-19 最终确认采用混合方案，而非照搬任一预览：

- **B「编辑部案头」作为主框架**：使用窄轨侧栏，把主要空间让给完整内容卡和画布；
- **吸收 A「书页卡墙」的项目信息区**：保留当前项目、继续上次工作和真实待处理标题，但用可展开信息区承载，避免重新撑宽全局侧栏；
- **书写页采用 C「沉浸阅读架」**：进入正文后降低导航存在感，以正文和少量写作动作作为视觉中心；
- 三者只是结构来源，正式界面仍须统一控件、主题、间距和交互，不在同一页面拼贴三套视觉语言。

本条只确认方案，不代表已经进入正式应用施工。

## 十一、实施顺序

### P0：先解决可见性与模型地基

1. 工作台、卡片墙、待打磨便笺、侧栏和编辑器动作层级；
2. 独立设置页与 AI 助手预设；
3. 读者遐想正名、桥段类型/解法、构思首页；
4. 地图/地域/组织/社会关系文件模型与兼容读取。

### P1：把模型变成可工作的界面

1. 人物与组织档案、可拖拽关系画布；
2. 地图卡片、地域卡片、地图转场与两级地图画布；
3. 章节卡片、快捷便笺、全局搜索、光标拆章与本地校对；
4. 力量体系模板、时代词条与方法视角。

### P2：真实使用后再决定

- 版本差异比较；
- 更复杂的地图背景与图层；
- 桥段统计图表；
- 其他只有反复出现真实需求才复活的能力。

不进入路线：专注计时/热力图、自由白板、完整制图软件、一键 AI 写正文、自动规划或无确认写回。
