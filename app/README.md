# 工笔（app）

个人网文创作工具：拆书积累 → 灵感沉淀 → 构思写作。设计文档见仓库根目录
[docs/设计共识.md](../docs/设计共识.md) 与 [ADR](../docs/adr/)。

技术栈：Tauri 2 + React + TypeScript（编辑器后续接入 CodeMirror 6）。

## 开发

```bash
npm install
npm run tauri dev    # 开发运行
cargo test           # Rust 侧单元测试（在 src-tauri/ 下）
npm run build        # 前端类型检查 + 构建
```
