# 编辑器渲染层 · 图片内联与 callout 卡片

> 工单 #31/#32 决议（2026-09-13 访谈拍板）。基线：ADR 0005（推翻「编辑器内 `![]()` 渲染」判死）、设计共识 §四（插入块＝Obsidian 风格 callout、纯 markdown 可读）、[书库新建与展示.md](./书库新建与展示.md) §六（判死表首行由本单反转）、[拆书保存与模板.md](./拆书保存与模板.md)（书档块入家族）。
> 原则：**文件永远是纯 markdown 源码，一切渲染都是编辑器装饰层**——Obsidian 打开原样可读，导出链路零感知。

## 一、决议总览

| 问题 | 决议 |
|---|---|
| 图片 | 内联渲染本地附件图：等比缩到编辑器列宽、保持清晰；点击弹原图大图查看器 |
| callout | 五件套＋书档共六种渲染成卡片：隐藏 `> [!xxx]` 语法、标题行常驻、内容可折叠 |
| 作用范围 | 拆书编辑器、书写编辑器、构思便签编辑器三处共用同一扩展包 |
| 文件内容 | 零改动（仍是 markdown 源码）；导出仍删图、callout 仍按引用行输出 |
| 交互边界 | 到「聚焦块还原源码」为止——不做整页预览模式 |

## 二、图片内联渲染

- **匹配**：markdown 图片语法且目标为**本地相对路径**（`附件/…`、`../附件/…`）；网络 URL 不渲染（维持链接文本）。
- **显示**：widget 替换链接文本；等比缩到编辑器列宽内（不超原尺寸放大）；解码原图、CSS 缩放——**清晰可读优先，不要糊缩略图**；同一图多处引用复用同一加载。
- **占位**：加载中/文件缺失显示占位条（路径＋提示），不崩编辑器、不阻塞输入（异步解码）。
- **点击**：弹出大图查看器——原始分辨率、可缩放、Esc/点遮罩关闭；查看器内不做标注/裁剪。
- **授权**：打开编辑器时对当前书/项目附件目录 `grant_asset_scope`（复用现有命令与授权时序）。

## 三、callout 卡片

- **家族与样式**：点评／如果是我写／原文截图／出场人物／小结／书档 六种，各配色＋图标；手写的未知 `[!xxx]` 按通用卡片渲染，不报错（只提示不校验的老纪律）。
- **结构**：标题行（图标＋类型名）常驻；内容区＝块内其余引用行；点标题行折叠/展开，折叠态显示类型名＋首行摘要。
- **折叠不持久化**：刷新/重开默认全部展开。
- **编辑模型（所见即所得的边界）**：**聚焦块＝源码、失焦块＝卡片**——光标移入该块时整块还原 markdown 源码（含 `> [!小结]` 行）可直接编辑，光标离开恢复卡片。语法行只在聚焦瞬间可见，不做常显开关。
- **插入路径不变**：工具栏插入块、AI 采纳落盘仍是源码文本，渲染层自动接管。

## 四、边界与不做

- 不做整页预览模式（编辑/预览切换）。
- 不渲染外链图片；不做图片编辑/标注。
- 不做 callout 自定义类型管理（未知类型通用卡片兜底即可）。
- 导出链路零改动：图片整条删除并计数（现状）、callout 按普通引用行输出（现状）。

## 五、实现增量

- **前端**：
  - 新模块 `editorRender.ts`（暂名）：CodeMirror ViewPlugin＋Decoration——图片 widget、callout 块卡片装饰、聚焦还原；三编辑器（`EditorPage`/`WritingPage`/`MarkdownEditor`）挂同一扩展包。
  - `ImageViewer.tsx`（暂名）：大图查看器（遮罩＋缩放＋关闭）。
  - 附件目录授权时序接入编辑器打开流程。
- **Rust**：无新命令（`grant_asset_scope` 已有；快照/保存链路无涉）。

## 六、测试决策

- **接缝**：本特性几乎纯前端装饰层，Rust 无增量——**不硬造测试接缝**，沿仓库既有纪律：前端手动验收清单＋tsc 构建门；渲染不改变文件内容这一点用「保存前后文件字节不变」手动核验。
- 手动验收清单：粘贴截图即见清晰图；点击放大/缩放/关闭；缺文件占位；六种 callout 卡片化、未知类型兜底；聚焦还原源码、失焦回卡片；折叠摘要；OB 打开文件语法完好；导出结果与现状一致；深/浅主题与六套编辑器背景下均可读。

## 七、判死与复活信号

| 判死 | 复活信号 |
|---|---|
| 整页预览模式 | 想看整体排版而非单块效果 |
| 外链图片渲染 | 真往库里贴网络图 |
| 图片标注/裁剪 | 复习时想在图上画重点 |
| callout 自定义类型管理 | 六种之外反复手写新块名 |
| 折叠状态持久化 | 每次打开都要重新折叠同一批块 |
| 语法行常显开关 | 聚焦还原不过瘾、想一直看源码 |
