工笔 · UI 视觉方向预览

工单 #39 的可挑选方向示意。三个方向共用同一套色相（既定设计共识已锁定：暖纸底 + 朱砂强调 + 深色侧栏）， 差别只在结构参数——间距刻度 / 圆角 / 阴影层次 / 动效时长与缓动 / 图标描边与尺寸 / 字号层级。 下面的小应用是示意稿，不是最终界面；请把鼠标移到导航、按钮、表格行、卡片上感受动效差异。

甲 · 纸墨精修

低圆角 · 线为主 · 静

延续现有纸墨气质，把散落的硬编码收成刻度；层级靠线 + 表面色阶表达，不用阴影（纸不会浮起来）。 动效克制、几乎只在状态变化时出现。最稳、最像「文房」，但「现代化」的观感提升最小。
