# 期待感/目标三线 · 时间线网格 ＋ 写作侧欠账提醒

> 工单 #7 决议。**代理最优解、用户未事前授权、可事后否决**——本单是 HITL 拷问工单，为在用户不在场时推进地图，按 #4/#6 先例由代理给出最优解；否决即重开本单重议。
> 基线：设计共识 §九（期待感/目标三线，短/中/长期，参考 Plottr 时间线网格）、ADR 0002（文件为唯一数据源）/ ADR 0004（写路径原子＋读-合-写）、#4（正文一章一文件、章序在文件名、锚点坐标＝章＋引文）、#5 §6.3（侧栏预留「本章欠着的期待/目标」区块；三线线定义与 项目.yaml 情节线对齐由本单定）、#6（伏笔底座可复用：长期对象＋状态机＋章序数锚点＋看板分组；三线另立文件、另立页签）。
> 方法论背景：期待感是网文留人的核心——主角懦弱人设是期待、开头的美女是期待、金手指信息差是期待；目标线是「下一步去哪里」的章末启下。三线要能在时间线网格上看到：哪条线多久没推进了、哪章埋的期待还没兑现。

## 一、定位与边界

- 三线＝**期待/目标的跨章节长期线索**，按档位（短/中/长）分三行，与伏笔同构不同表。两个半区共用同一份数据：
  - **长期管理**（构思侧）：「三线」页签——时间线网格，看哪条线多久没推进、哪章埋的期待还没兑现。
  - **写作中提醒**（书写侧）：侧栏看到本章埋/兑现了什么、还欠着哪些线。
- **正文零污染**（与 #6 同款）：锚点＝「章序数 ＋ 引文」，存项目内的三线文件——正文在任何 md 工具里原样可读。
- 不做：AI 期待建议/自动识别、跨书三线、三线↔情节线/单元自动关联、三线↔伏笔自动互转。期待是人的判断，应用只做记录与提醒（ADR 0003 同款边界）。

### 与伏笔的关系（工单问题 2 的答案）

- **数据分家、底座共用**。#6 已定「三线另立文件、另立页签，不挤进伏笔.yaml」——本单不翻案。共用的底座落在代码里：新模块 `thread.rs` 收口「锚点（章＋引文）＋单文件整表读写＋现扫失配与未推进派生」；`foreshadow.rs` 与 `expectation.rs` 各自只写自己的状态值、操作与视图。
- 两套皮的区别只在**类别/档位**两个字段与**时间线网格**这一个视图；交互纪律（右键标注、看板分组、引文失配只提示、约定值只提示不校验）完全一致。
- 不做「一套 UI 两套皮」的抽象层：伏笔看板是按状态分组的列表，三线看板是网格＋详情卡，视图差异大于共性，强行合并只会两边都别扭。

### 与情节线（项目.yaml）的关系（#5 §八留给本单的问题）

- **不对齐**。情节线是排布视图的行（结构属性，随项目定义）；三线是跨章节线索（内容属性，按档位分）。按名引用会让两套词表打架（#13「只提示不校验、归并靠人」的纪律下尤其糟）。
- 一条期待线不绑定情节线；判死「三线↔情节线自动关联」，复活信号＝想按情节线回看期待（届时加一个可选「线」字段，只提示不校验）。

## 二、数据：`项目/《书名》/三线.yaml`

- 落点：项目根下一个文件（与 `伏笔.yaml`/`排布.yaml` 同款纪律：单文件读-合-写、应用受管、保存整表重写、条目内手补的未知键会丢）。
- 形态（中文键）：

```yaml
- 名: 主角何时亮出金手指
  类别: 期待              # 期待｜目标（约定值只提示不校验）
  档位: 短                # 短｜中｜长
  状态: 已埋              # 待埋｜已埋｜部分兑现｜已兑现｜弃用
  埋设:
  - 章: 1                 # 章序数（第几个章标题，1 起；与伏笔/桥段同一套坐标）
    引文: 他摸了摸怀里的木匣，没敢打开。
  兑现:
  - 章: 9
    引文: 木匣开了，里面是一枚旧铜钱。
    类型: 阶段            # 阶段｜终结
    说明: 只露了金手指的一角
```

- 字段：

  | 键 | 形态 | 必填 | 说明 |
  |---|---|---|---|
  | 名 | 字符串 | ✔ | 期待线的身份；同名＝同一条（追加埋设/兑现），不新建 |
  | 类别 | 字符串 | | 期待｜目标；缺省＝期待 |
  | 档位 | 字符串 | | 短｜中｜长；缺省＝中 |
  | 状态 | 字符串 | | 五态约定值；缺省按「待埋」显示 |
  | 埋设 | 列表 | | 每条＝`章`（序数）＋`引文`（选中原文） |
  | 兑现 | 列表 | | 每条＝`章`＋`引文`＋`类型`（阶段｜终结）＋可选`说明` |

- 锚点为什么是序数＋引文、未编号章节不参与标注、懒生成、解析失败显式报错——全部沿用 #6 §二，不重复。

## 三、状态机与操作

- 五态：**待埋 → 已埋 → 部分兑现｜已兑现**；旁支 **弃用**（可恢复）。语义与伏笔逐字对应（埋设＝写进正文、兑现＝还账），动词从「回收」换成「兑现」——网文语境里期待/目标都是「兑现」。
- 操作：

  | 操作 | 入口 | 效果 |
  |---|---|---|
  | 新建待埋 | 三线看板 | 填名字＋类别＋档位；重名报错不合并（与单元/伏笔同款） |
  | 记为三线 | 书写页选中文字右键 | 同名不存在→新建（已埋，用弹窗里选的类别/档位）；已存在→追加埋设（待埋→已埋），类别/档位以已有为准 |
  | 兑现三线 | 书写页选中文字右键 | 追加兑现记录（阶段/终结＋可选说明）；终结→已兑现，阶段→部分兑现（弃用不覆盖） |
  | 改状态 | 看板详情卡 | 五态任切（含弃用/恢复） |
  | 改类别/档位 | 看板详情卡 | 重分类（两值/三值任切） |
  | 删除 | 看板详情卡 | 确认后整条删除 |

## 四、时间线网格（构思侧「三线」页签）

- 位置：构思项目页「三线」页签，紧跟「伏笔」（都是跨章节线索），页签带条数徽标（与单元/伏笔同款）。
- 布局：**行＝档位（短/中/长）**，**列＝章**（一章一列，横向滚动）；一条线＝一条横向条。
  - 条起点＝最早埋设章，条终点＝最近兑现章；**未兑现的线延伸到「当前」（全书最大章序）**，从最近一次锚点起画虚线尾巴，右侧标「已 N 章未推进」，超期整条标红。
  - 同一档位有多条线时按泳道上下叠放（贪心区间着色，互不遮挡）。
  - 条上每个埋设/兑现锚点画一个点（埋设＝空心、兑现＝实心）；条内显示线名。
  - 已兑现＝闭合条（灰绿）；弃用＝灰色；待埋的线不在网格里——网格上方单列「还没落位」区，标注后自动落位。
  - 手写的未知档位单列「其他档位」行（只提示不校验，改回三档即归行）；未知类别原样显示。
- 章刻度：第 1 章＋每 10 章一个刻度标签；行标签左侧吸附。
- 点条＝选中，网格下方出**详情卡**：名、类别/档位/状态三个下拉、埋设与兑现锚点列表（点章跳到书写板块并选中引文）、删除。
- 空态：没有正文且没有条目时给一句引导（先到书写里写第一章；线可以先「新建」记下来）。

## 五、未推进统计与超期

- 对状态∈{已埋, 部分兑现}的线：`未推进章数 = 当前最大章序 − 最近一次锚点章（埋设或兑现都算推进）`。
  - 与伏笔的差别：伏笔只算埋设章（#6 §四），三线的兑现同样推进线索，故算最近锚点。
- 超期阈值**按档位**（Rust 侧常量，前端镜像）：**短 8 章**（约两个桥段）｜**中 20 章**（约一个单元）｜**长 50 章**（跨 2~3 个单元）。只提示不拦截；手写的未知档位按中档阈值提示。复活信号＝用户想调（届时进 项目.yaml）。
- 侧栏「还欠着的线」按「未推进章数 ÷ 档位阈值」的紧迫度降序；网格用条长、虚线尾巴与标红直接表达紧迫度（网格本身按档位与章序排布，不重排）。

## 六、书写侧联动（#5 §6.3 预留位）

- **右键菜单**（编辑器选区非空时）新增「记为三线」「兑现三线」，与伏笔两项并列；无选区不出菜单；未编号章当场提示先编号。
- **侧栏两个区块**（沿用 #5 区块拼装，空区块不渲染）：
  1. **本章三线**：本章埋设的线（名/类别/档位/引文）＋本章兑现的线（名/类型/说明）；点条目在正文里选中引文。
  2. **还欠着的线**：未兑现（已埋/部分兑现）的线按「未推进章数 ÷ 档位阈值」的紧迫度降序，最多 5 条，超期标红；底部一行「共 N 条未兑现，见构思→三线」。没有未兑现线时不渲染。
- **不画正文装饰**（与伏笔不同）：两种下划线叠在正文里会把稿子画花，三线的价值在时间线全景与侧栏提醒。复活信号＝写作时真想在正文里看见期待锚点。
