## 一、一句话结论

工笔现在的问题不是功能少，而是**功能按数据模型摆放，没有按创作动作摆放**。拆书、构思、书写三处各有一套名词和页面，彼此靠"跳转"和"关联字段"连接，所以人得先学会这个工具，才能开始写。

新设计的核心是一句话：**一副骨架，三种用法。**

- 拆书是把别人的书**逆向拆开**：书 → 单元 → 桥段 → 章 → 拍，每个桥段标出"类型 → 解法"；
- 构思是把自己的书**正向搭起来**：读者想看什么（类型）→ 怎么写（解法）→ 排成单元与桥段；
- 书写是把每个桥段**逐拍落地**：这一章是哪一拍、读者在等什么、该埋什么。

三者用的是同一副骨架、同一套词。于是拆书收来的解法，会自己出现在构思选类型、写到那一章的时候；随时冒出来的灵感，先收进随身本，再一拖就落到骨架上。

骨架之外还有两处存放，对应两个"不止一"：

- **灵感库**：不属于哪一本书的东西，先养在这里。不按"它是什么"分九类，而按"将来会落进骨架的哪一层"分六格；拆书收来的解法和自己想的、换皮抽出来的，都在"爽点"这一格。
- **我的书**：构思是一个书架，可以同时养好几本，也可以同时写几本。

## 二、现状评估

| 现象 | 后果 |
|---|---|
| 构思有 14 个页签（首页、大纲、读者遐想、矛盾、桥段库、单元、伏笔、期待感、目标、排布、人物、世界观、地图、开头），人物内再分三视图，地图内再分四页签和三种方法视角 | 打开构思先看到一张名词清单，要先理解模型才知道从哪开始 |
| 拆书产出的类型/解法、点评、"如果是我写"，到了构思和书写里看不见 | 拆书变成"存档"，而不是"取材"；三板块之间只有跳转，没有流动 |
| 理论被做成字段或体检，而不是动作：章节拍在拆书里不标、在书写里只是一段提示；类型圈只是一张列表；2:1 节奏只在体检里出现 | 理论"在场"但用不上，作者感觉不到它在帮忙 |
| 灵感捕获要先选九类之一 | 记一笔之前先做一次决策，正是最容易放弃的时刻 |
| 新建人物摊开十一个可选字段 | 正是用户描述的"畏难"场景 |
| 人物关系、社会关系、地图语义三套画布，拆书却没有画板 | 该画的地方不能画，能画的地方要学三套规则 |
| 三个板块用同一种侧栏加条卡的外观 | 无法做到"拆书时专注、构思时生发、书写时沉浸" |

保留下来的正确判断：文件是唯一数据源；AI 只帮人想、不替人写正文；不评分、不阻断写作；先收下、后整理。

## 三、重读理论：我从原文里读出的七件事

下面每一条都直接决定了一处设计。原文在仓库 `理论基础/`。

1. **拆书的目的是俯瞰骨骼，不是盯一字一段**（《浅谈用工程化思维》）。一本书约 40~50 个单元、200~300 个桥段；桥段可归为几种类型，每种类型有很多解法；全书就是把解法按次序排布。
   → 拆书台的左侧是一条"脉络"，章节在上面一眼排开，圈几章就是一个桥段；解法跨书汇总进灵感库的"爽点"格，按类型归档。

2. **取材是被"遐想"驱动的**（《一本书是如何诞生的》）。作者先用三天想清楚读者想看的十条，再针对每一条去找写得好的作品看。拆书不是独立的爱好，而是给类型圈找解法。
   → 类型圈里每一类都显示"已收集几种解法"；一类都没收集时，它显示为空心圈，点开就是"去拆哪几本"。拆书和构思从此互相驱动。

3. **矛盾是在取材过程中冒出来的，记在手边的本子上**（同上）。"其实就在我搜集那些素材的过程当中，我手边空白的本子上就已经多了一个又一个的剧情。"
   → 随身本必须在拆书时伸手就有，而且零决策：先写下，来源自动记上，以后再落位。

4. **人设是在纸上分阵营、连线画出来的；人物可以由几个素材"合三为一"**（同上）。关系里"有没有解开的秘密"会生出剧情。
   → 人物页的主体是一张画板：阵营是圈出来的区域，关系是线，秘密是虚线；人物的"灵感来源"可以直接挑拆书里记过的人物。

5. **爽点要从心而发，要抓住动心的那一瞬间，并给读者理由**（香蕉两篇）。研究桥段而抓不住心动，是"从心情到桥段再到别人的心情，损耗了很多"。
   → "动心"是拆书里的一等动作：读到哪里心里动了，点一下，写一句为什么；构思桥段时先问"读者会在哪一刻最爽"；书写卡住时，搭子问的是情绪与理由，而不是替你写。

6. **节奏有可学的刻度**（工程化帖与风青阳）。桥段四章：代入/信息差约 5:5，拉扯到结尾起势约 9:1，兑现写透，善后与启下；单元间成长:打击约 2:1，张弛交替，相邻单元关联紧可防养书；主线是脊椎，立意是灵魂。
   → 这些刻度变成**可视化**，而不是检查表：桥段卡上有四章的拍条；书写时页面上方有一条节拍条，告诉你写到一章的哪里；剧情台下方有一条节奏波形，连续三个成长单元时轻轻提一句。

7. **方法有流派，不是普适规律**（三翻四震与三翻四抖之争、宅猪三种地图法）。
   → 流派方法只做"可开的视角"和"可改写的问题"，放在工具箱里，默认不出现。

## 四、五条设计原则

1. **一处一事。** 每个空间只为一件事服务：拆书专注于拆，构思专注于生发，书写专注于写。不在书写页摆构思的表单，也不在拆书页摆写作统计。
2. **一问一答。** 新建任何东西都从一个问题开始，答一句就成立；后续问题一个一个地出现，从不摊开一排空框。问题用人话，不用术语，例如问"TA 想要什么？"，而不是摆一个"目标"字段。
3. **素材自己找上门。** 在你需要的那一刻，相关素材自动出现在手边：选了类型就出现灵感库里这一类的解法，写到那一章就出现参考解法和该埋的伏笔。灵感库是用来逛、用来翻的，不是非得先去查才能用。
4. **先收下，后安放。** 捕获时零决策；分类不靠填表，靠"落位"——把一条灵感拖到矛盾池，它就是矛盾；拖到人物身上，它就补进人物。安放只有两条路：用在某一本书里，或者换个皮收进灵感库，留给以后的书。随身本是要清空的，灵感库是越攒越好用的。
5. **功能在需要的那一刻出现。** 三种出现方式：就地出现（选中文字才出现"埋伏笔"）；有了才显（埋下第一条伏笔，"线索"页才出现）；工具箱打开（地图三法、三线看板等流派化工具，默认收起）。

## 五、信息架构

### 5.1 全局

左侧窄轨从上到下：**案头 · 拆书 · 灵感 · 构思 · 书写**，底部是**随身本 · 搭子 · 设置**。窄轨上每个入口是一枚印章式的单字（案、拆、灵、思、写），下面配小字名称；所在空间的印章填色。顺序就是工作流：拆书收来的进灵感库，灵感库喂给构思，构思排好了去写。

- **随身本**不是一个板块，而是一个随时可开的抽屉，配全局快捷键 `Ctrl+J`（"记"）。
- **搭子**（AI）以就地入口为主，抽屉对话为辅。
- **构思**直接进你上次在想的那本；标题上方一行「‹ 我的书 · N 本」回到书架。**书写**打开你最近写的那本；从某本在写的书的构思里点书写，就打开这本；同时在写几本时，顶栏一排书名一点就换。
- 跨书的动作都只多一步"选书"：拆书台的"带去"、随身本的"给哪本书"、灵感库的"带去"，都用同一排书签切换，默认是你正在构思的那本。

### 5.2 旧功能去向

| 旧 | 新 |
|---|---|
| 灵感库（九类卡片） | **灵感库六格**，按去处分：故事卡 → 故事；金手指、题材、书名 → 胚子；角色 → 人物；组织、世界观 → 设定；片段、技法 → 字句；另加"爽点"一格收类型与解法 |
| 待整理灵感 | **随身本**：捕获零决策，种类是可选标签；每条先猜好去处，攒多了"一条一条过" |
| 转生（卡片 → 书内实体） | **带去**：保留单向，并在灵感库那一条上留下痕迹（用在哪本书、哪里，换成了什么） |
| 项目列表 / 构思首页 | **我的书**（正在写一本 ＋ 在酝酿几本，每本一条生长线）与构思·核心（这本书是什么） |
| 大纲纸面、主线里程碑 | 核心页的"主线 / 立意"两问 ＋ 剧情台顶部的主线脊 |
| 读者遐想（类型圈） | 核心页中央的一个真正的"圈"，圈内类型挂解法，圈外写不写的 |
| 矛盾、桥段库、单元、排布、开头 | 合成一张**剧情台**：左边矛盾池，右边排布，下面节奏条；点单元展开桥段；第一格是开篇 |
| 人物、组织、关系画布、社会画布 | 人物页：一张画板（阵营即框、关系即线）＋ 右侧档案 |
| 世界观、地图、地域、时代、力量体系 | 世界页：设定条目，力量体系与地图带引导问题；三种地图法在工具箱 |
| 伏笔、期待感、目标三个看板 | **线索**：书写中选中文字就地埋设；剧情台上可叠加显示；有了才出现一页总表 |
| 待打磨便笺 | 起稿 / 定稿：起稿的卡片是虚线，定下来变成实线（工笔先起稿、后勾线） |
| AI 侧栏与助手预设 | 搭子：读者、编辑、抬杠、拆书教练、人物五种身份；就地入口为主 |
| 章节总览、全局搜索、光标拆章、校对、导出 | 保留，收进书写的章节抽屉、`Ctrl+K` 搜索与工具箱 |

## 六、各空间设计

### 6.1 案头：今天从哪里开始

打开应用落在案头。它只回答三件事：

1. **接着做什么**。最大的一张卡是最近写的那本的"继续写第三十八章"，同时写出这一章在构思里的意图（"拉扯，结尾让萧珩开始出手"）和今日字数（几本加在一起）；旁边几张小卡：继续拆、随身本最近两条（攒到 5 条时出现"整理一下"）、**其他的书**（也在写的，一行写到第几章、这一章是哪一拍；在酝酿的，一行长到哪一步、下一步只问一句）。
2. **这本书的来路与去处**。一条横向的流，四站：拆书（收了多少解法和动心）→ 灵感库（多少条、多少还没用过）→ 构思（几类读者想看、几个矛盾和单元）→ 书写（写了多少章），以及反向的箭头：构思缺哪类解法（取材缺口）、写作中冒出几条灵感待落位。
3. **今天想一想**。只给一个问题，来自这本书真实的缺口，例如"驭下收心这一类，灵感库里一种写法都还没有"。

不放统计图、热力图和完成度。

### 6.2 拆书：专注于看清骨头

**书斋**只有一面书架：正在拆的那本放在最上面，下面是"取材缺口"——把我的书里每一本的类型圈扫一遍，列出灵感库里解法太少的类型（标着是哪本书缺）和建议去拆的书，再下面是封面书架。新建拆书只要输入书名、回车。第一轮的"解法谱"并进了灵感库的"爽点"格（6.3），书斋右上角一个入口直达。

**拆书台**是三栏：

- 左：**脉络**。章节竖向排开，每章一行梗概，右侧小色点是这章的章节拍。点一章、Shift 点另一章，就圈出一个桥段，桥段以色带呈现。点色点可以标拍，弹出的说明直接用理论原话解释六个拍。
- 中：**拆书稿**。顶部是书档（书名、成绩、简介、金手指、心得，空的只显示问句）；每章是标题＋梗概＋随手插入的块：点评、如果是我写、原文截图、出场人物、钩子（"是什么让我想看下一章"）、小结、动心。`Ctrl+Enter` 开下一章。鼠标停在某章时，右侧出现三个小按钮：**动心**、**插入**、**带去**。
- 右：**画板**，可开关、可全屏。

**标桥段只问三句**：读者在等着看什么（类型，从词表选或自己写）→ 作者是怎么做到的（解法，一句话；下面列出同类型已收的解法以免重复）→ 哪里让你动心（可跳过）。完成后提示"收入灵感库 · 爽点：××类第 N 种"。

**带去**：鼠标停在某章时的"带去"，先用一排书签选给哪本书（默认是正在构思的那本），再选带什么：一颗矛盾种子、挂到类型圈的一种写法、某个人物的参照，或者先丢进随身本。

**画板**是一张简单的白板，只做拆书需要的几种东西：人物（圆）、事件（方）、便签、连线（带关系名，"有秘密"变虚线）、框（阵营）、手绘笔。它和拆书稿是连着的：

- **摆上出场人物**：从拆书稿的"出场人物"块里取人名，围成一圈；
- **事件发展**：从已标的桥段和梗概生成一条事件流，再手动拉出支线；
- 也可以从空白开始。

### 6.3 灵感库：不属于哪一本书的，先养在这里

随身本解决"来不及想就先记下"，灵感库解决"它不属于这本书，但我不想丢"。前者要清空，后者要越攒越好用。几十上百条以后，靠的是三件事：**按去处分格**、**轻筛选**、**用过留痕**。

**六格，按"将来会落进骨架的哪一层"分：**

| 格 | 收什么 | 将来去哪 |
|---|---|---|
| 胚子 | 题材、金手指、书名 | 长成一本新书 |
| 故事 | 人物＋困境＋爽点预期（即故事卡片） | 某本书的矛盾池 |
| 爽点 | 类型 → 解法；拆书收来的、自己想的、换皮抽出来的 | 类型圈、桥段 |
| 人物 | 原型：一句话就能立住的人 | 某本书的人物 |
| 设定 | 世界、组织、规矩、物件 | 某本书的世界 |
| 字句 | 对白、描写、一种写法 | 书写时的页边 |

按去处分，是因为翻库的时候你问的是"我现在缺什么"：给类型圈找写法就翻爽点，想开新书就翻胚子，写到一半想找句狠话就翻字句。九类里"金手指卡 / 题材卡 / 书名卡"这种按形态的区分，在找东西时没有用处，所以只留作胚子上的小标签。

**爽点这一格就是第一轮的"解法谱"**，按类型再分一层（"掉马甲 · 4 种写法"），所以"掉马甲有几种写法"一眼就能回答。每条标着来源：拆书来的（《庆余年》第 88–90 章）或自己想的（随身本 · 九月）。

**找东西：** 左边是六格和爽点的类型目录，各带条数；上面一个搜索框（一句话、一个类型、一本书名都行），三个筛选——拆书来的 / 自己想的、还没用过、动心过。总览页每格只露最新三张，"看全部"再展开。

**用过留痕：** 每张卡片下面写着它去过哪里，例如"用在《长街镖行》· 矛盾池"；爽点写"换过 2 次皮"，每次记着用在哪本书、哪里、换成了什么样子。同一个结构可以反复换皮用，痕迹让你知道上次怎么用的、别重样。

**带去：** 胚子的按钮是"用它开一本新书"；其余的是"带去"——一排书签选哪本书，再选去处（故事 → 矛盾池；爽点 → 想一颗种子或挂到类型圈；人物 → 人物；设定 → 世界；字句 → 页边）。带去后原卡还在，只多一行痕迹。

**翻三张：** 不知道下一本写什么的时候，从胚子、故事、爽点各翻一张（优先没用过的），问一句"放在一起，像不像一本书？"。像，就"揉成一本新书"——胚子成为一句话，故事进矛盾池，爽点进类型圈；不像就再翻。

灵感库也会主动出现在别处：类型圈点开一类，右侧就是这一类的写法；拆书书斋的取材缺口按灵感库计数；世界页空着时提示"设定里有 N 条还没用过"。

### 6.4 构思：让人更想往下想

**我的书：构思是一个书架。**

- 最上面是**正在写**的几本，最近写的排第一：封面、一句话、写到哪个单元、写了几章、几个单元几个人物、池里还有几颗种子；按钮是"接着写第三十八章"、"进构思"，以及"先放一放"（回到在酝酿，写到哪一章记着，回来"接着写"）。
- 下面是**在酝酿**的几本，每本一张卡：一句话、一条**生长线**（一句话 → 类型圈 → 人物 → 排布 → 开写）标出它长到哪儿了，再加**一个**下一步问题，例如"读者看到「末世里开当铺」，最想看到哪几个场面？"。生长线只标位置，不打分，也不要求按顺序走。卡片底部写着它是怎么来的（"拆《局护送未亡人》第一章时冒出来的"）。
- 最后一格是**开一本新书**：只要一句话（谁，在什么处境下，要做什么），或者从灵感库拿一个胚子——书名胚子填进书名，金手指胚子填进金手指，题材胚子成为一句话。开了就直接进这本书的核心页。
- **开写**：在酝酿的书排好第一个单元后，卡片上的下一步变成"开写"。第一章从第一个单元的第一个桥段开始；还没排桥段的，先起一个草稿桥段，页边照样告诉你这一拍该做什么，解法空着时列出灵感库里这一类的写法。
- 可以同时写几本。书写打开最近写的那本，案头最大的卡也跟着它走；任何一本书，不论在写还是在酝酿，都随时可以进去想，拆书和随身本也随时可以往里送东西。

每本书的构思页都一样：头部是书名和一句话创意，上方「‹ 我的书 · N 本」回书架；还没开写的书，右上角显示生长线。下面只有四页：**核心 · 人物 · 剧情 · 世界**。埋下第一条伏笔后，出现第五页"线索"。右下角常驻一张"想一想"卡。新书的空页不摆空表单，只给一个问题和一个按钮，例如人物页："还没有人。先想主角：TA 叫什么、一句话是什么样的人？"

**核心：这本书凭什么让人想看。**

- 左栏是几个一句话：一句话创意、金手指（以及"它能怎么用"）、主线（主角到底要做什么）、立意（还没想好时只显示一个问题）、打磨（这个题材里哪些是我擅长的）。
- 中间是**类型圈**：一个真正画出来的圈，圈内是读者想看的各类内容，每个圆圈的数字是拆书里已收集的解法数；还没取材的类型是空心虚线圈。圈外写"不写的"（如频繁换大地图、带兵打仗）。
- 点任一类型，右侧出现：读者想看什么（可改）、我的桥段里用了几次、灵感库里这一类的写法（拆书来的和自己想的都在，可"借来想想"：换到这本书的主角身上，变成一颗矛盾种子，并在那条写法上记一次换皮）、搭子"再想三种"。

**人物：在纸上分阵营、连线。**

- 中间是人物画板：阵营是框，关系是线，秘密是虚线并带一个"秘"字。
- 左边是名单，按阵营分组。右边是档案：头像、一句话、已经回答过的问题。
- **新建人物只有两步**：叫什么？一句话说说 TA。之后档案下方出现一排"可以再想想"的问句：TA 想要什么？和主角是什么关系？藏着什么秘密？从哪来的灵感，像谁？让 TA 说句话听听？放张图？点一个才展开一个输入框，回答后变成档案里的一行。没回答的问题从不以空框出现。
- 每个问句旁都可以"请搭子想三个"；打开人物对话工具后，可以直接和 TA 聊。

**剧情：从种子到排布，一张台子。**

- 顶部是**主线脊**：主线里程碑排成一条线，标出"你写到这里了"。
- 左边是**矛盾池**：每颗种子一句话（谁、遇到什么麻烦、读者等着看什么爽）；随身本里给这本书的待落位灵感也堆在这里。
- 右边是**排布**：单元从左到右排开，第一格是开篇（多个版本＋一组可改写的开篇自查问题）。每张单元卡写着"给读者的感受"、类型、成长或打击、紧绷或舒缓。
- 把种子拖进排布，只问一句"这个单元最后要给读者什么感受"，它就成了单元。
- 下面是**节奏条**：一条张弛波形，点的颜色表示成长或打击。连续三个成长单元后若接一次打击，显示"正是 2:1"；若没有，轻轻提一句。旁边写着篇幅估算（已排约多少章，池中矛盾约够多少章），回答"够不够撑起一本书"。
- 点一个单元，下面展开它的**桥段**：每张桥段卡写"类型 → 解法"、读者最爽的那一刻、以及四章的拍条。新建桥段同样三问，选了类型之后，灵感库里的同类解法直接列在输入框下面。
- 打开"显示线索"，伏笔和期待线以弧线跨在单元上方，未收的线拖向右侧。

**世界：够用就好。**

设定条目卡片墙。力量体系带四个引导问题（每一级能做到什么、代价是什么、主角的例外在哪、下一级让读者期待什么）；地图卡带一个问题（离开这里时，哪些熟悉的人和没解开的谜要一起带过去）。千丝万线、莲花、千层饼三种视角在工具箱里打开后才出现。

**想一想卡**：每次只给一个问题，问题引用这本书里真实的名字和缺口，例如"林晚和萧珩之间，有没有一件只有他们俩知道的事？"。可以写下来（答案自动落到对应位置）、和搭子聊、或换一个。

### 6.5 书写：沉浸于写

- 进入即正文。窄轨淡出，顶栏在打字时变淡；正文用楷体或宋体，行距宽。
- **同时写几本**：顶栏左侧一排书名，一点就换。每本记着自己写到哪一章、这一章的意图和页边状态；今日字数是几本加在一起的。只在写一本时，这排书名不出现。
- **页边"本章"**（可收起）：这一章属于哪个单元、哪个桥段、第几章；这一拍该做什么（理论原话的白话版）；读者在等什么；解法与拆书里的参考；该埋的伏笔；出场人物。最后一行是"下一章：兑现"。
- **节拍条**（可在工具箱关闭）：页面顶部一条细线，按本章目标字数分段，标出你写到了哪里；接近结尾时，页边轻轻提示"该让他开始出手了，但别一章装完"。
- **选中文字**出现气泡：埋伏笔、拉期待、记一笔、润色。埋伏笔只问名字和大概什么时候收。
- **卡住了**：搭子不给正文，只问四个问题——读者此刻最想看到什么？配角此刻在想什么？主角凭什么这么做？这一章的爽是否透支了后面？每个问题给三个方向，可以记进随身本。
- **完稿**：一章写完，直接进入下一章，页边换成下一章的意图。
- 章节抽屉按单元和桥段分组，还没写的章也已经按构思显示好它的拍。
- 人名悬停显示人物一句话档案。

### 6.6 随身本：零决策地记，一条一条地放

**记：** `Ctrl+J` 或窄轨按钮，弹出一张只有一个输入框的小卡。上方自动带上来源（"拆《××》第五章时""写第三十八章时"）。"给哪本书"按场景默认：在构思和书写里是当前这本，在拆书、灵感库、案头里是"不给哪本书"；点一下轮换。种类（剧情、人物、爽点、设定、金手指、书名、字句）可标可不标。回车记下。

**放：** 抽屉分"待落位"和"最近落位"。随身本是要清空的——它不是灵感墙，灵感墙是灵感库。每条都先**猜好去处**（标了"人物"又给了《灯下黑》，就猜《灯下黑》· 人物；标了"爽点"没给书，就猜灵感库 · 爽点），一键照猜的放。不照猜也只有两条路：

- **用在书里**：一排书签选哪本书，再选矛盾池、人物、类型圈或世界。人物和类型圈再问一步"补给谁"，可以"新来一个人"。
- **收进灵感库**：六格选一格。

**换皮：** 收进"爽点"，或者一条剧情/爽点刚用在书里时，会问一句"去掉人名和这本书的设定，它还剩下什么？"，再选它属于哪一类"读者想看"。搭子可以帮着抽，比如"寿宴上让太子替萧珩挡了一刀"抽成"最该杀他的人，阴差阳错替他挡了一刀"（掉马甲）。抽出来的是灵感库里一条"自己想的"爽点，并记着它第一次的皮。不是每条都值得抽，"不用了"一键跳过。

**整理一下：** 攒到 5 条，案头和抽屉顶部出现"攒了 N 条 · 整理一下"。点开后一次只看一条：回车照猜的放，→ 先放着，Esc 不整理了。最后告诉你这一轮落进书里几条、收进灵感库几条，"不急的，下次攒多了再来"。

也可以直接把一条从抽屉拖到剧情台的矛盾池或排布里。

### 6.7 搭子：在思考发生的地方出现

- 就地入口：标桥段时"这是什么类型"、类型圈"再想三种解法"、人物问句"想三个"、想一想卡"和搭子聊"、书写"卡住了"与"润色"。
- 抽屉对话：五种身份——**读者**（看简介说想看什么，即遐想）、**编辑**（指出毒点和人设前后不一）、**抬杠**（专挑不合理处，对应"给读者理由"）、**拆书教练**、**人物**（扮演书中人）。
- 边界不变：只给想法和问题，不写正文；任何建议都要人点"采纳"才落盘。

### 6.8 渐进披露：工具箱

设置里的"工具箱"把功能分为三组，每个开关下写明打开后它会出现在哪里。

## 七、视觉方向：素纸 · 细线 · 一点朱

- **概念**：工笔画先起稿、后勾线、再上色。界面以温暖的素纸为底、细墨线为骨，只在主动作和印章处用一点朱砂。起稿状态的卡片用虚线，定稿后变实线。
- **色彩**：取工笔矿物色。朱砂用于主动作与印章；石青标拆书；石绿标构思；赭石标书写；藤黄标随身本与灵感；胭脂与花青用于人物和关系。夜间模式是"夜墨"：深墨底、纸色字，矿物色提亮。
- **字体**：标题用思源宋体；拆书稿、随身本与正文用霞鹜文楷（可换宋体）；界面控件用思源黑体。
- **空间个性**：拆书台像摊开的书桌（三栏、左窄右宽）；构思像一间留白很多的画室（大圈、大画板、浮动的问题卡）；书写只有一张纸，四周的东西都退下去。
- **动效**：切换空间时像墨在纸上晕开；新建的人物和单元从一点墨扩散出来；不做弹跳、不做彩色渐变。

## 八、数据模型（重写）

原则保留：**文件是唯一数据源**，Markdown ＋ YAML ＋ JSON Canvas，随时可用 Obsidian 打开。理由：个人工具要用很多年，纯文本最耐久，AI 也能直接读。结构按新设计重排，旧库提供一次性迁移（迁移前自动整库备份）。

```
库/
  拆书/《书名》/
    拆书.md            # 书档 ＋ 每章梗概 ＋ 块（点评、如果是我写、截图、出场人物、钩子、小结、动心）
    骨架.yaml          # 桥段：起止章、类型[]、解法、情绪、各章的拍
    画板/<名>.canvas   # JSON Canvas 1.0
    附件/
  灵感库/
    胚子/<名>.md       # 正文一句话；标签（题材|金手指|书名）、来源、动心
    故事/<名>.md       # 一句话核心（人物＋困境＋爽点预期）、类型标签、来源
    爽点/<类型>/<名>.md # 只放"自己想的"解法：一句话、情绪、来源、第一次的皮
    人物/<名>.md · 设定/<名>.md · 字句/<名>.md
  书/《书名》/           # 可以有很多本
    核心.md            # frontmatter：状态（酝酿|正在写）、怎么来的；一句话、金手指及用法、主线、立意、打磨；圈内类型与读者想看；圈外
    人物/<名>.md       # 一句话、阵营、灵感来源[]、起稿|定稿；问答以小标题写入正文
    画板/人物关系.canvas  # 人物节点引用人物文件；阵营为框；关系为边（关系名、秘密）
    剧情.yaml          # 主线里程碑、单元次序、单元属性（成长|打击、紧绷|舒缓、地图）
    剧情/矛盾/<名>.md · 剧情/单元/<名>.md · 剧情/桥段/<名>.md
    世界/<条目>.md
    线索.yaml          # 伏笔、期待、目标合一：类别、档位、埋设锚点、回收记录
    正文/<NNNN 标题>.md
    附件/
  随身本/<时间>.md     # 正文 ＋ 来源、给哪本书（可空）、可选种类；落位后只剩一行去向
  词表.yaml
```

关键变化：

- **桥段在拆书和构思里是同一种形状**（类型、解法、情绪、拍）。灵感库的"爽点"格是两处之和：拆书 `骨架.yaml` 里的桥段（扫描得到，不另存一份）＋ `灵感库/爽点/` 里自己想的。
- **画板采用 JSON Canvas**（Obsidian 原生格式）。人物关系以人物关系画板的边为唯一来源，取代 `关系.yaml`；手绘笔迹以扩展字段保存。
- **类型圈、大纲、主线、排布合并**为 `核心.md` 与 `剧情.yaml` 两处。
- **伏笔、期待、目标合并**为 `线索.yaml`，状态机沿用原设计。
- **灵感库九类目录改为六格**（第一轮写的"取消"作废）：故事卡 → 故事；金手指卡、题材卡、书名卡 → 胚子（原类别留作标签）；角色卡 → 人物；组织卡、世界观卡 → 设定；片段卡、技法卡 → 字句；未分类 → 随身本待落位。迁移时逐条搬，不丢字段。
- **痕迹记在去处，不记在来处。** 带去的种子、类型、人物素材在自己的文件里写 `来源: 灵感库/爽点/掉马甲/xxx` 或 `来源: 拆书/《书》/骨架.yaml#桥段`；灵感库卡片上的"用在哪里 / 换过 N 次皮"是反向扫描出来的。删掉一颗种子，痕迹自然消失，不会有两处不一致。
- **随身本只是待落位区。** 落位就是把内容移进目标位置（某本书，或灵感库某一格），随身本里留一行去向，供"最近落位"查看。
- **多本书**：`书/` 下每本一个目录；`核心.md` 的"状态"区分酝酿和正在写，可以有几本同时在写。写到哪一章从 `正文/` 推出来；"最近写的是哪本"是应用状态，不写进库。生长线不存储，每次从内容算（有一句话、类型圈 ≥3 类、人物 ≥2、单元 ≥1、正在写）。
- 退役：`类型圈.md`、`大纲.md`、`主线.yaml`、`排布.yaml`、`关系.yaml`、`地图结构.yaml`、`伏笔.yaml`、`三线.yaml`、`灵感库/<九类>/`（迁入六格）。
