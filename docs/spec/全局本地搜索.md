# 全局本地搜索（T18 / #71）

补充《书写增强》§三。沿用文件为唯一数据源（ADR 0002）；搜索不建立内容副本、不调用 AI。

- 任意主要管理页、正文编辑页及沉浸模式下，Ctrl+K 打开同一搜索窗口。Escape 关闭并恢复原焦点；输入框内上下选择、回车打开；Tab 不离开窗口。
- 搜索拆书 Markdown、灵感、项目资料、章节（含未编号文件）、人物、组织、地图、地域、单元、桥段、矛盾、世界观、开头、伏笔和期待线。结果按实体类型分组，显示项目/类别、命中字段、原始文件行号和片段，可现读全文。
- 只扫描规定创作目录，跳过导出、附件、隐藏文件和应用缓存。空查询不扫描，最多返回 200 个实体；超过上限明确提示缩小查询。查询防抖、旧响应丢弃，磁盘扫描在后台任务运行。
- 文件身份是路径；伏笔与期待线身份是项目路径＋类型＋条目名。同名人物/组织、地图/地域及不同项目的同名对象互不混淆。
- 损坏的线索表告警并跳过；损坏 frontmatter 的 Markdown 仍可搜索原文，显示读取提示，不修复或覆盖。
- 选择章节跳入既有书写编辑器并定位正文命中；选择笔记、桥段、组织和灵感打开既有详情（灵感现读最新卡片）；地图/地域切换到对应页签并展开、定位原卡片；伏笔定位原看板条目，期待线选中原详情；项目打开构思首页。拆书打开命中的实际文件。
- 搜索选择可能重挂正文编辑器，必须先由编辑器确认保存成功；保存失败/冲突时保留原缓冲、留在搜索窗口提示，关闭后可继续裁决。单纯打开/查询/展开搜索不触发保存。
