# 书写增强：章节总览、速记、搜索、拆章与校对

> 2026-09-19 用户逐项确认。本文补充 [书写编辑器](./书写编辑器.md) 与 [导出与发布](./导出与发布.md)。原则：写作板块只保留直接帮助写作、查找与发布前检查的能力，不引入专注计时、连续写作和热力图。

## 一、章节卡片总览

- 作为书写项目内的可选展示，与章节列表读取同一批章节文件；
- 卡片显示章号、标题、状态、字数、摘要和本章意图；
- 摘要来自明确的章节摘要字段时展示，没有则不自动生成，也不拿正文首段冒充；
- 点击进入章节；第一版不拖拽排序、不触发重编号；
- 章节正文不在卡片中全文展开，这是“完整内容卡”的明确例外。

## 二、写作快捷便笺

- 复用灵感速记，不建立项目便笺库；
- 从写作页快捷键或小入口呼出，用完立即收起；沉浸模式隐藏入口但保留快捷键；
- 自动关联当前项目与章节，保存为待打磨便笺；
- 后续可整理为普通灵感卡、故事卡或桥段草案；
- 保存后立即出现在灵感库的待打磨区和书写页相关内容中。

## 三、全局本地搜索

- `Ctrl+K` 打开全局搜索/快速打开；
- 搜索拆书、灵感、项目、章节、人物、组织、地图、地域、单元、桥段与伏笔；
- 结果按类型分组，显示正文命中片段并可展开；
- 回车打开对象；
- 只读本地文件，不调用 AI；
- 不扩成可执行任意动作的命令中心；页面局部筛选继续保留。

## 四、光标拆章

- 用户在正文光标处显式发起；
- 对话框预览原章保留范围、新章起始内容、拟用章号与标题；
- 确认后先保存并为两章建立快照，再把光标后的正文移入新章；
- 失败时不得留下半拆文件；
- 不自动调整单元/桥段区间，只提示可能需要检查。

## 五、主动校对

检查仅在用户发起「校对本章／校对全书」时运行：

1. 中文标点与成对符号；
2. 重复字、连续重复词；
3. 用户自定义易错词；
4. 人名、地名和专有名词一致性。

- 不内置平台敏感词检查；
- 报告列出问题、上下文与跳转入口，不自动修改正文；
- 规则全在本地运行；
- 写作过程中不持续画红线；
- 与导出/发布的校对入口共享底层，但本规格取代旧规格中“的地得＋内置错词种子为首版核心”的范围。

## 六、明确不做

- 专注计时、连续天数、热力图、效率排名；
- AI 自动写正文或全书批量润色；
- 章节卡拖拽重排；
- 默认开启版本 diff；只有用户反复比较版本时再复活。

## 七、验收

- 章节卡和章节列表不会形成两套章序来源；
- 写作速记只产生现有灵感卡，不产生第二套便笺文件；
- 全局搜索离线可用且不会发送正文；
- 拆章在任一步失败时原章与新章保持可恢复的一致状态；
- 校对零写回，所有修改由人完成。

## 八、整体验收（#53）

章节卡与关联速记（#72）已整合到当前分支，与已有全局搜索、光标拆章和
主动校对共用书写页。`Ctrl+Alt+O` 打开章节总览，`Ctrl+Alt+N` 打开本章速记；
拆章与校对从键盘可达的「页面」菜单进入，`Ctrl+K` 保留全局搜索入口。
总览、速记和拆章对话框在内部循环 Tab，Esc 取消并把焦点还给正文；执行
保存或拆章时不允许关闭。校对使用非模态面板，可 Tab 返回正文，Esc 关闭。
沉浸模式中关闭这些工具不同时退出沉浸。

关联便笺始终引用灵感库的原卡片，在本章侧栏只读展示完整正文和待打磨状态；
保存后立即刷新，重开章节或返回书写板块时重新读取，不另存一份项目便笺。
卡片上的章节关联可从灵感库跳回正文；源章节失效后保留便笺。
速记保存通知常驻的灵感库立即重读；两处共用章节关联解析规则。
章节摘要与本章意图同时存在时都展示，不互相遮盖。
校对范围明确分为本章、全书与章节区间，仅本章传入单文件约束；
其他章节的命中先通过正常保存闸打开目标章，再核对该章内容指纹并定位。
