# 我的书：多本并存，可以同时写几本

构思不止一本书，写也可能同时写两本以上。决定：`书/` 下每本一个目录，`核心.md` 里的状态只有"酝酿｜正在写"两态，可以有几本同时在写；书写打开最近写的那本，顶栏一排书名切换。写到第几章从 `正文/` 推出，"最近写的是哪本"是应用状态、不写进库；生长线（一句话 → 类型圈 → 人物 → 排布 → 开写）不存储，每次从内容算。

## Considered Options

- **同时只有一本正在写**（我原先的倾向，用户否决）：书写和案头因此不必选书，但不符合同时写两本的实际。

## Consequences

凡是跨书的动作（拆书"带去"、随身本"给哪本书"、灵感库"带去"）都多一步选书，统一用同一排书签，默认是正在构思的那本；每日字数是几本加在一起的。
