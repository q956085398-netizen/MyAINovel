# 组织与社会关系兼容升级（T11 / #58）

组织是一文件实体：`构思/组织/<组织名>.md`。可选中文 frontmatter 键为「目的」「所在地」「矛盾」「秘密」；正文自由书写。读取与编辑保留未知键，既有档案编辑带内容指纹，同名创建及过期指纹拒绝覆盖。首版编辑不改组织名；删除组织保留失效关系，由人处理。

社会网唯一来源是 `构思/关系.yaml`，未升级时兼容读取旧 `构思/人物关系.yaml`。新文件一旦存在，不再合并或回写旧网。节点身份由「起类／止类」（人物或组织）与名称组成，同名人物和组织不冲突。

「关系」条目沿用「起」「止」「类型」「描述」「秘密」；成员关系以人物为起点、组织为终点，另有可选「职位」及「任职」（现任／前任，缺省现任）。关系类型自由输入，每个人物可以有多条组织关系。未知顶层键、图例条目键、关系条目键以及画布布局均保留。现有人物画布与 AI 的人—人关系读路径投影新网，人—人编辑只替换对应关系与图例，保留组织关系。

入口：项目「人物与组织 → 组织与归属」。复用完整内容卡与宽编辑框，组织卡直接展示所有已填写内容和派生的成员关系。失效人物或组织引用显示提示，不自动删除。组织档案与社会网均不保存人物或组织副本。

兼容升级先只读预览，再显式确认。预览列出将创建和更改的文件：分组名生成组织（已存在同名组织只引用，不覆盖）；每个人物的旧分组生成成员关系，并仅从该人物 frontmatter 移除「分组」。正文、其他字段和旧人物关系文件保留。未升级时，旧人物分组仍在名单编辑框继续显示和编辑。

确认时重新计算并核对整份预览，外部修改、文件新增或目标碰撞要求重新预览；损坏人物头部、组织档案、图例或关系表拒绝升级。取消预览磁盘零变化。

写前日志保存在 `.gongbi/社会升级.json`，记录全部前镜像与待写结果。每份文件通过同目录临时文件与原子替换发布，正常错误自动撤回。进程中断后，「恢复中断的升级」显式撤回，再重新预览；日志未清理前，组织和关系写操作拒绝继续。恢复前检查日志路径和全部文件版本，遇到外部修改保留原文件与日志，不覆盖。完成事务后删除日志。

验证以临时项目上的领域操作为边界：预览／取消、确认与重开、多组织关系增改删、组织 CRUD 与内容指纹、未知字段、损坏数据、碰撞、人—人画布窄写及中断恢复。类型检查与生产构建验证前后端契约。
