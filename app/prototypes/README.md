## `gongbi-blueprint.html` —— 总设计原型（2026-10-03）

配套方案：[docs/总设计方案-2026-10.md](../../docs/总设计方案-2026-10.md)。「一副骨架，三种用法」：
拆书攒下的「类型 → 解法」进灵感库，在构思里被用上，构思定下的情绪在书写时落地，随身本一路接住灵感。

- 左轨：案头 / 拆书 / 灵感 / 构思 / 书写，下方随身本、搭子、设置；所有场景都可点、可改，数据只在内存里
- 灵感库：六格（胚子、故事、爽点、人物、设定、字句），爽点按类型分；搜索与三个筛选；「带去」先选书；「翻三张」可揉成一本新书
- 构思：标题上方「‹ 我的书」是书架，三本书（《灯下黑》《长街镖行》在写，《明日当铺》在酝酿），可开新书、开写、先放一放
- 书写：同时在写几本时，顶栏左侧一排书名一点就换；每本记着自己写到哪
- 随身本：每条先猜好去处；攒到 5 条出现「整理一下」，一条一条过（`Enter` 照猜的放、`→` 先放着、`Esc` 不整理了）；收进爽点时「换个皮」
- 底部原型条「▶ 走一遍工作流」：十步串起拆书 → 灵感库 → 随身本 → 我的书 → 构思 → 书写，每步可点「帮我…」代做；`←` `→` 翻步
- `Ctrl+J` 随手记一笔（回车记下，点「给哪本书」轮换）；`Esc` 依次关闭弹层 / 整理 / 抽屉
- 画板（拆书台右侧、构思 · 人物）：双击新建，从节点右侧小圆点拖出连线，`V` `P` `E` `N` `C` `F` `B` 切工具，`Delete` 删除
- 原型条右侧切夜墨；设置页可切正文字体，「工具箱」里的辅助功能可逐个开关
