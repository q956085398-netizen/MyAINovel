# 拆书与构思共用一副骨架：桥段同形

拆书是把别人的书逆向拆开，构思是把自己的书正向搭起来，两边原本各有一套名词和字段，拆书收来的解法到了构思和书写里看不见。决定：桥段在拆书的 `骨架.yaml` 和构思的 `剧情/桥段/` 里是同一种形状——起止章、类型（可多个）、解法、情绪、各章的拍——于是拆书收来的解法不经转换就出现在类型圈、新建桥段的三问和书写页边，灵感库的"爽点"格也只是扫描两处之和、不另存一份。

## Consequences

拆书桥段条目从四键（起/止/类型/解法，见 `docs/spec/拆书yaml-schema.md`）扩到六键，并推翻 #11 里"章节拍 v1 判死"的结论（`docs/spec/拆书编辑器.md`）：拍不再是要逐章填的字段，而是脉络上可点可不点的色点、书写时的节拍条，标不标都不影响其他功能。
