# 地图、地域、组织升格为独立实体，并分开保存空间网与社会网

旧模型把地图降成 `项目.yaml` 的字符串和世界观「地理」词条，把组织降成人物的单一「分组」字符串；它们无法稳定承载地域层级、换图承接、多组织身份、画布布局与跨对象引用。决定将地图、地域、组织升格为一对象一文件的书内实体，并分别以 `构思/地图结构.yaml` 保存地图/地域关系、转场与地图画布位置，以 `构思/关系.yaml` 保存人物—人物、人物—组织、组织—组织关系与社会画布位置。

## Considered Options

- **继续使用世界观词条和字符串引用**（取代）：文件简单，但关系无法可靠展示或迁移，用户也无法在整体地图与局部地域之间导航。
- **所有关系共用一张总表**（否决）：地图包含、地域通道与师徒、成员等社会关系语义差异过大，会把图例、校验和迁移绑成一个难以维护的模型。
- **画布只存应用状态**（否决）：手工布局是作者对故事结构的整理结果，应随项目迁移和备份。

## Consequences

地图是整体故事空间，地域是地图内部区域；一个项目可有多张地图，地域可进一步展开为地图。地图画布与关系画布都从文件数据派生，允许拖拽、固定和自动整理，但不成为脱离实体的自由白板。旧 `世界观/` 地理与势力词条、`构思/人物关系.yaml` 继续兼容读取，只在用户确认后升级，不静默搬移或覆盖。
