# 工笔 · 设计共识

> 个人网文创作工具：拆书积累 → 灵感沉淀 → 构思写作。AI 是助手，人的主观能动性是主角。
> 本文档是 2026-09 拷问会话的共识总结。术语见 [CONTEXT.md](../CONTEXT.md)，重大决策见 [docs/adr/](./adr/)。

## 一、定位与边界

- **应用名**：工笔（仓库仍为 MyAINovel）
- **用户**：纯个人使用，不考虑通用性与多人场景
- **平台**：Windows 优先，界面全中文
- **AI 边界**：AI 只处理人写下的内容（梳理、建议标注、提炼小结、激发灵感）；不提供小说原文一键拆解（ADR 0003）
- **板块划分**：拆书（拆书书库 + 灵感库）｜构思（人物画布、世界组织、伏笔、期待感、目标）｜书写（编辑器）。v1 重点拆书，构思与书写只留骨架

## 二、技术形态（ADR 0001）

- 独立应用，非 Obsidian 插件：避免"装修 Obsidian"的分心，换专注、可深度定制的操作界面
- 技术栈：Tauri 2 + React + TypeScript + CodeMirror 6
- 自建成本最高的部分是编辑器与文件管理；数据保持纯文本，迁移成本有界

## 三、数据（ADR 0002）

- **文件为唯一数据源**：Markdown + YAML + 附件图片；应用索引（SQLite 等）只是可弃缓存
- 库文件夹可指向现有 Obsidian vault 子目录（如 `写作学习/拆书分析/`），兼容"根目录散文件"与"一书一文件夹"两种既有布局，不搬动、不改写用户文件
- **双文件制**：每本书 = 正文 `.md` + 同名 `.yaml`（书级元数据、章列表、桥段 span、类型/解法标注）。yaml 懒生成：导入旧稿时先入索引，用户首次做结构化标注时才落盘
- 新建拆书采用一书一文件夹：`《书名》/拆书.md`；`.yaml` 与 `附件/` 懒生成，首次结构化标注/贴图时才落盘（同 #13 懒生成纪律，见 docs/spec/书库新建与展示.md）

## 四、拆书编辑器

- **渐进式模板**，不是填空表单：
  - 书级：基础字段（书名、成绩、简介、金手指）＋可后续补
  - 章级：只给前缀（默认"第X章"，前缀模板书级可配）；写完按 **Ctrl+Enter（或按钮）显式开下一章**，自动带出下一个前缀；"空行回车自动开章"留待以后
- **插入块**（斜杠菜单 `/` 或工具栏，Obsidian 风格 callout，纯 markdown 可读）：点评、如果是我写、原文截图、出场人物、小结
- **桥段标注**（结构化动作，非正文块）：选中几章 → 标记为桥段 → 填类型/解法 → 存入该书 yaml
- 截图直接粘贴，自动存入该书 `附件/` 并嵌入
- 必填字段只有：书级四项、每章梗概、桥段类型标注；其余全可选

## 五、书库首页

- 按书浏览（含成绩等元数据）＋ 全文搜索 ＋ **桥段跨书筛选**（按类型/解法，回答"'掉马甲'有多少种解法"）
- 统计图表等桥段标注积累到几百个再议

## 六、灵感库

- 九类卡片：故事卡、金手指卡、题材卡、片段卡、角色卡、组织卡、世界观卡、技法卡、书名卡 ＋ 未分类兜底
- 通用字段：标题、正文、来源、标签、关联（链接到拆书记录/桥段/其他卡片）；故事卡另有"一句话核心（人物＋困境＋爽点预期）"
- **导入旧 `灵感.md`**：按原有标签归类，杂项落未分类，之后再归档
- **故事卡可一键转生为单元草稿**（矛盾 → 单元的成长路径）

## 七、AI 侧边栏

- VSCode 式侧边栏对话，可自配多个供应商（OpenAI 兼容接口：名称＋Base URL＋Key＋模型），流式输出，多会话历史
- 可携带当前文档作为上下文
- 编辑器命令：「梳理选中内容」「建议类型/解法标注」「提炼小结」——AI 给初稿/建议，人确认后才落盘

## 八、v1 里程碑（顺序即开发顺序）

1. 应用骨架 ＋ 打开库文件夹（识别两种既有布局）
2. 拆书编辑器（前缀推进、五插入块、截图粘贴、双文件制）
3. 书库首页（浏览、全文搜索、桥段类型/解法跨书筛选）
4. 灵感库（九类卡片、导入旧灵感、故事卡转生）
5. AI 侧边栏（多供应商、流式、文档上下文、三个编辑器命令）
6. 构思/书写板块骨架占位

## 九、v2 备忘（不入 v1）

- 伏笔状态机（待埋 → 已埋 → 已收/部分收/弃用，含埋设章节与超期统计）——v2 第一优先
- 期待感/目标三线管理（短/中/长期，参考 Plottr 时间线网格）
- 人物关系画布（参考 Campfire Relationships）
- 技巧方法库（收录龙空等方法论文章）
- 酒馆式人物卡对话（与自己的角色聊天找灵感）
