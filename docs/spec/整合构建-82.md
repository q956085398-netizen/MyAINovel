在第一次启动前对旧库副本建立文件 SHA-256 清单，将清单放在库外；新库也在首次选择后建立清单。可在 PowerShell 使用下面的只读方法，修改两个路径为验收副本及库外记录文件：

```powershell
$acceptanceRoot = (Resolve-Path -LiteralPath 'C:\验收\旧库副本').Path.TrimEnd('\')
$acceptanceOutput = 'C:\验收记录\旧库-before.json'
$acceptanceRows = @(Get-ChildItem -LiteralPath $acceptanceRoot -File -Recurse -Force |
  ForEach-Object {
    [pscustomobject]@{
      Path = $_.FullName.Substring($acceptanceRoot.Length + 1)
      SHA256 = (Get-FileHash -LiteralPath $_.FullName -Algorithm SHA256).Hash
    }
  } | Sort-Object Path)
ConvertTo-Json -InputObject $acceptanceRows |
  Set-Content -LiteralPath $acceptanceOutput -Encoding utf8
```

每套库分别执行六条流程，并在 960×640 与 1280×800 检查键盘、可见焦点、减少动效、正文无横向阅读滚动和画布操作空间：

4. 设置四页签、助手预设创建/修改/删除与旧会话快照；固定命令和人物对话保持独立。
