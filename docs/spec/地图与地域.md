# 地图、地域与地图画布

> 2026-09-19 用户逐项确认。基线：ADR 0002、ADR 0004、[ADR 0008](../adr/0008-first-class-maps-regions-and-social-graphs.md)、[构思数据模型](./构思数据模型.md)。本文取代旧模型中“地图＝项目.yaml 字符串＋世界观地理词条”的决定。

## 一、领域边界

- **地图**是整体故事空间；一个项目可有多张地图；
- **地域**是地图内部的局部区域；地域可进一步展开为另一张地图；
- **地图结构**是地图、地域、关系、转场和画布布局的共同来源；
- **地图转场**只处理地图之间的叙事承接；地域之间的相邻、通道、往返属于地域连接；
- 地图画布是既有数据的视觉表达，不是自由白板或制图软件。

## 二、文件布局

```text
构思/
  地图/<地图名>.md
  地域/<地域名>.md
  地图结构.yaml
  组织/<组织名>.md
  关系.yaml
  世界观/<时代名>.md   # 类别: 时代
```

每个对象一文件；关系与布局分别进入地图网、社会网。目录与文件均懒生成。

### 2.2 地域文件

```markdown
---
尺度: 城市
剧情功能: 权力中心与身份危机的主舞台
人物: [主角, 皇后]
组织: [新朝, 前朝暗线]
矛盾: [潜伏京城]
单元: [初入京城]
伏笔: [皇城地宫]
时代: [开国时代]
当地主线: 在新朝眼皮底下站稳脚跟
秘密: 地宫里躺着前朝真龙
展开为: 京城地图
待打磨: false
---

氛围、视觉印象、地域隐秘、当地历史与尚未解决的问题。
```

尺度种子为：地点｜村落｜城镇｜城市｜区域｜国家｜世界｜异界｜自定义。尺度只提示和筛选；包含关系必须显式记录，不能根据尺度猜。

## 三、地图结构.yaml

```yaml
地图关系图例:
  - 名: 核心附属
    有向: true
  - 名: 上下层
    有向: true

地域关系图例:
  - 名: 包含
    有向: true
  - 名: 相邻
    有向: false
  - 名: 通道
    有向: false
  - 名: 往返
    有向: false
  - 名: 隐秘联系
    有向: false

地图关系: []
地域关系: []
包含:
  - 地图: 人间
    地域: 京城

转场:
  - 起: 人间
    止: 仙界
    离开原因: 主角必须寻找失踪的师父
    先行人物: [师姐]
    提前线索: [仙界来客]
    随行未解问题: [师父失踪]
    返回条件: 找到跨界通道
    单元: [飞升前夜]

布局:
  全书: {}
  地图: {}
```

- 图例可增删改名，只提示不校验；
- 引用失效照常显示缺省节点，不自动删边；
- 坐标是作者整理出的项目数据，随项目保存；
- 读不懂的结构文件拒绝覆盖。

## 四、地图页

一级入口「地图」位于构思的“定书”组，内部只有一层副页签：

1. **全貌**：地图卡、全书地图画布与方法视角；
2. **地域**：地域完整卡片墙；
3. **转场**：地图转场列表与割裂风险提示；
4. **历史**：时代词条及其与地图/地域的引用。

地图卡管整体，地域卡管局部；两者默认完整显示已填写内容，编辑使用右侧宽详情面板。

## 五、两级地图画布

### 5.1 全书地图画布

- 以地图为主节点；
- 展示地图关系与地图转场；
- 双击地图进入单张地图画布；
- 千丝万线视角突出跨地图人物、组织、线索和事件；
- 莲花视角将核心地图置中、附属地图环绕，并突出返回路径与核心秘密；
- 方法视角是临时布局，只有用户点击「采用此布局」才覆盖保存坐标。

### 5.2 单张地图画布

- 展示该地图的地域、包含关系和地域连接；
- 默认只显示地图/地域；
- 可叠加人物、组织、矛盾/单元、主线里程碑、伏笔/地域隐秘；
- 人物和组织是附属小节点；情节对象默认作为地域标记和详情，不全部铺成大节点；
- 可选背景图片来自地图附件，地域节点可摆在图片上；不提供画笔、道路或地形生成。

### 5.3 编辑与布局

- 支持新建地图/地域、连关系、建转场、拖动、固定、详情面板编辑；
- 普通「自动整理」保留固定节点，只整理其余；
- 「全部重新布局」重排全部；
- 最近一次布局操作可撤销；
- 删除藏在对象上下文中并确认；
- 长正文不直接在画布节点里编辑。

## 六、理论视角

- **千丝万线**：查看地图之间已有多少熟悉人物、组织、线索和事件联系；
- **莲花**：查看核心地图、附属地图、返回路径与尚未揭开的核心秘密；
- **千层饼**：按时代查看同一地图/地域的历史层次。

三者可混用，不是项目模板或完成度检查。只有发生大地图转场时才提示检查割裂风险；地域内移动不触发。

## 七、兼容与升级

- 旧 `项目.yaml` 的地图名、世界观「地理」词条继续可读；
- 世界观地理词条提供「升级为地图／地域」动作；
- 世界观「势力」词条提供「升级为组织」动作；
- 升级必须展示目标文件和关系变化，由用户确认；
- 旧文件移入可恢复的兼容备份，不静默删除；
- 未升级内容保持原样可读。

## 八、验收

- 一个项目能创建多张地图，每张地图能包含地域；
- 地域可展开为另一张地图而不复制正文；
- 地图转场与地域连接不会混为一类；
- 卡片和画布编辑后读取的是同一份数据；
- 手动布局重开项目后保持；方法视角不会未经确认覆盖布局；
- 背景图缺失时画布仍可用；
- 旧地理/势力/人物关系文件未经确认绝不改写。
