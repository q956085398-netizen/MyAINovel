# 人物与组织完整档案（T12 / #68）

人物保存在 `构思/人物/<人名>.md`；组织沿用 `构思/组织/<组织名>.md`。卡片完整展示已填写字段与正文，沿用两列档案卡和宽编辑框，不产生第二份内容。

人物 frontmatter 可选键：形象图、 一句话身份、别名、年龄或年龄感、性别、性格关键词、当前目标、能力、弱点或代价、个人秘密。别名和性格关键词为列表，其余为自由文字。所有摘要都可空；小传、外貌、说话方式和人物弧继续自由写在正文，不强制模板。

形象图引用本地附件，通常为相对人物文件的路径，例如 `../../附件/人物.png`，不复制到另一个资料库。缺失或失效只提示图片无法显示，文字阅读与编辑继续可用。卡片展示原路径以方便核对。

人物卡的组织摘要从 `构思/关系.yaml` 的显式成员关系派生，包含组织、关系类型、职位、现任/前任、公开/秘密和描述；可同时展示多段关系。旧分组仅兼容读取和保留，通过「组织与归属」的预览升级转为成员关系，人物编辑不新增或修改分组键。损坏社会网明确报错，但不阻止阅读和编辑人物档案。

人物卡可进入编辑、定位人物关系画布或进入组织归属。组织卡完整展示目的、成员关系、所在地、矛盾、秘密和正文，点击标题编辑，组织关系入口定位本页成员关系区域；组织编辑中的正文图片以组织文件目录解析。

编辑框随载入结果携带内容指纹；保存前核对原文件，不一致时拒绝覆盖并保留编辑输入。保存仍合并未知 frontmatter 字段、原子替换文件。旧命令入参可缺省指纹，保持已有转生等操作兼容。

验证边界：临时库内保存和重新扫描人物档案、混合旧人物/新组织、清空摘要字段、保留未知字段与旧分组、过期版本拒绝覆盖；前端类型检查、生产构建、完整测试，以及模拟 IPC 的浏览器页面流程（完整阅读、失效图片、编辑保存、空字段新建、待打磨恢复、关系入口和窄屏布局）。浏览器验收不等同于真实 Windows 应用重启验收。
