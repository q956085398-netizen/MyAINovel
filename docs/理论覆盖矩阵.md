# 理论基础 → 产品机制覆盖矩阵

> 2026-09-19 复核。目的不是证明“每篇理论都做成字段”，而是检查重要创作动作是否有可见入口、合适的数据归宿和回到写作现场的路径。理论原文若属于个人经验或流派方法，只进入可删提示、技法卡或方法视角，不成为强制校验。

## 一、结论

工笔已经覆盖“矛盾 → 单元 → 桥段 → 排布、主线、伏笔/期待、人物关系”的宏观骨架；真正缺失或表达不足的是：

1. 读者遐想被「类型圈」术语遮住；
2. 桥段没有类型/解法配对；
3. 力量体系只有自由词条，没有思考引导；
4. 地图只是字符串，不能承载整体空间、地域、转场与历史层；
5. 人物档案和组织模型太薄，画布不能稳定表达社会关系；
6. 情绪已有目标和曲线，却缺少“情绪为何形成、靠什么传递”的辅助界面。

本轮决议补足这些思考界面，但不把方法论变成必填表单。

## 三、理论如何被看见

### 构思首页

只在当前上下文显示一个可关闭的问题，例如：

- 读者看到这个题材会默认期待什么？
- 这套力量体系靠什么让读者期待下一阶段？
- 离开当前地图时，哪些熟悉人物或未解问题会一起过去？
- 这个桥段与前一个桥段用了同一种解法吗？

不显示“理论完成度”。

### 技法卡

适合收录三翻四震、三翻四抖、特定开篇技巧等可选方法。用户可以保存、改写、关联桥段；应用不把全文复制到每个项目。

### 方法视角

千丝万线、莲花、千层饼只改变地图数据的突出方式和提示问题，不改变底层结构，也不未经确认覆盖手动布局。

## 五、后续审计纪律

新增理论或参考项目时，先回答：

1. 它解决作者真实经历过的问题吗？
2. 应成为结构化数据、可删引导，还是技法卡？
3. 保存后在哪里重新出现？
4. 是否与已有概念重复造词或重复存储？
5. 能否只提示而不阻断写作？

五问没有答案前，不新增字段或页面。
