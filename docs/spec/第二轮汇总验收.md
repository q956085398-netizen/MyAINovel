## 尚未完成的验收

总规格 Testing Decisions 最后一条要求真实旧库、新库及 Windows 应用重启。
当前会话的原生应用控制能力被禁用，不能把浏览器模拟或测试的重读声称为此项通过。

建议使用日常旧库的完整副本，并准备一个临时空文件夹作为新库。不要在唯一原库上
做迁移验收。记录副本验收前后未编辑文件的内容指纹，应用设置和创作内容分开核对。

两套库分别完成下列流程，并关闭、重开工笔复核：

| 流程 | 操作及重启后的通过条件 |
|---|---|
| 内容卡/便笺 | 读长正文与全部已填字段；收起、搜索展开；进出待打磨后仍为同一文件及原次序 |
| 人物/组织 | 同名异类、多组织身份；拖动、固定、整理未固定、重排撤销；档案与关系共用数据 |
| 地图/地域 | 多地图、地域展开地图、连接与转场；拖动、固定、布局撤销；方法预览未采纳不写盘 |
| 独立设置 | 四页签、供应商与预设管理；旧会话快照不随预设改变，固定命令和人物对话隔离 |
| 编辑器 | 动作菜单、选区动作、折叠排版；章节总览、关联速记、搜索、拆章预览、主动四项校对 |
| 配色 | 三配色各切浅/深/跟随系统，编辑器背景独立；重启后偏好保留 |

在常见笔记本宽度下检查横向阅读滚动、画布空间、键盘焦点与减少动效。
旧数据不迁移仍可读；迁移预览后取消不得改创作文件；确认迁移后可重开且保留未知键。
