## 一、前提与边界

- **色相不动**：暖纸底 + 朱砂强调 + 深色侧栏 + 编辑器沉浸背景，是既定设计共识（#17 个性化设置、#24 主题落地、ADR 0002）。三个方向**共用同一套色相与同一套组件结构**，差别只在结构参数：**间距刻度 / 圆角 / 阴影层次 / 动效时长与缓动 / 图标体系 / 字号层级**。
- **布局与信息架构不改**（#35 范围声明）：不改栏位、不改导航结构、不改页面分区。
- 每条参数都能直接落成 CSS 变量，**不是形容词**。

## 二、现状体检（为什么需要这一次统一）

对 `app/src/App.css`（3084 行）实测：

| 维度 | 现状 | 问题 |
|---|---|---|
| 圆角 | 4 / 5 / 6 / 7 / 8 / 9 / 10 / 12px 全都在用（6px 出现 23 次、8px 18 次） | 八个档位无语义，靠手感挑 |
| 字号 | 10.5 / 11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 14.5 / 15 / 16 / 17 / 18 / 19 / 22 / 26 / 42px | 13 与 12.5、14 与 14.5 混用，层级读不出来 |
| 间距 | gap 1/2/4/5/6/8/10/12/14/16/22px；padding 4~36px 十余个值 | 无基准刻度，多数不是 4 的倍数 |
| 阴影 | 全站仅 8 处，值彼此无关 | 没有层次语言，浮层深浅各写各的 |
| 动效 | 全站仅 **3 处** `transition`（opacity .15s、box-shadow .15s） | 交互几乎无反馈，界面「死」 |
| 图标 | 无图标体系，只有 `⚙ 设置`、`×`、`✓` 三个字形 | 侧栏/工具条缺视觉锚点，扫描全靠文字 |
| 主题 | CSS 变量组机制已就绪（浅/深两组，229 处 `var()`） | **机制是对的，缺的是值** |

结论：机制（变量组 + 两主题 + 六纹理 + 沉浸编辑器）已经对了，这一轮要补的是**刻度**。三方向都是在既有机制上**加一层 token 刻度**，不动结构。

## 三、三个方向

三个方向的**小应用并排预览**见配套 HTML（浅色 + 深色各一份，可直接 hover 感受动效时长差异）。

---

### 甲 · 纸墨精修（低圆角 · 线为主 · 静）

**一句话**：延续现有纸墨气质，把散值收成刻度；层级靠**线 + 表面色阶**表达，不用阴影（纸不会浮起来）。

| 维度 | 参数 |
|---|---|
| 间距 | 4px 基准刻度 **2 / 4 / 8 / 12 / 16 / 24 / 32 / 48**；页面 `30·34px`，控件 `6·14px`，卡片 `12·14px` |
| 圆角 | 控件 **4** · 卡片/表格 **6** · 弹窗 **8** · 徽标胶囊 `999` |
| 阴影 | 只弹窗一档 `0 12px 32px rgba(43,42,38,.18)`；卡片零阴影，靠 1px 线 + surface 色阶 |
| 动效 | **120ms** `cubic-bezier(.2,0,0,1)`；只做底色/描边/透明度，**禁位移与缩放** |
| 图标 | Lucide 线性，**16px / 1.5 描边**（正文内联 14px），单色随文本 |
| 色彩层级 | **4 层表面** `bg → surface → panel → paper` + 1 描边层；强调色只出现在可点动作与当前项，不做大面积填充 |
| 字号 | UI 13 / 次要 12 / 页题 20 / 编辑器正文 15·17（编辑器字号归 #33 排版设置，本方向不动） |

- **两主题适配**：沿用既有机制——深色＝整组翻深（背景压暗、纸面提亮一档、强调色降饱和），**层级关系（线与色阶）在两主题下同构**，所以不存在「深色下阴影消失导致层级塌掉」的问题。这是甲最省心的一点。
- **六套背景适配**：原样保留，方向甲不与编辑器抢戏（编辑器本就是「纸」，外围同样是纸；纹理即层级）。
- **代价**：现代化观感提升最小，属于「精修」而非「换脸」；如果期待「一眼看出变新了」，甲会不够。
- **选它的信号**：你喜欢现在这个调子，只是觉得「到处差一点点」；长时间写作时不想界面有任何「动」的东西。

---

### 乙 · 现代通透（中圆角 · 柔和阴影 · 有呼吸的动效）

**一句话**：向 Typora / Notion / Linear 的现代感靠——面板轻微浮起、圆角柔和、动效有呼吸感，间距整体放宽一档。

| 维度 | 参数 |
|---|---|
| 间距 | 4px 刻度放宽一档 **8 / 12 / 16 / 24 / 32 / 40**；页面 `32·40px`，控件 `7·16px`，卡片 `14·16px` |
| 圆角 | 控件 **8** · 卡片 **10** · 弹窗 **14** · 徽标胶囊 `999`；表格外框随卡片 |
| 阴影 | **三档**：静置 `0 1px 2px rgba(43,42,38,.06)` / hover `0 4px 12px .10` / 浮层 `0 16px 48px .22` |
| 动效 | **180ms** `cubic-bezier(.2,.8,.2,1)`；hover 微抬（阴影加深）、弹窗 `scale .98→1`、切页淡入 |
| 图标 | Lucide 线性，**18px / 1.75 描边**；侧栏导航图标与文字同列，可配淡色底 chip |
| 色彩层级 | **3 层表面 + 阴影表达高度**；hover / active / 选中 三档状态色齐全（现在只有 active 一档） |
| 字号 | UI 13 / 次要 12 / 页题 22 / 编辑器正文 15·17（不动） |

- **两主题适配**：浅色下阴影承担层级；**深色下阴影退场，改用「表面提亮一档」表达同一层级**（深色里阴影本来就看不见，这是成熟做法）——即层级语义不变、实现按主题切换。强调色在深色下降饱和提亮（`#a8432f → #cf7a62`，已有值）。
- **六套背景适配**：六套纹理照旧；编辑器纸面加一层**极淡内描边（1px 线，不用阴影）**，与外围的「浮起」区分开——保证编辑器仍然是「纸」而不是「卡片」。
- **代价**：更多阴影 + 微量位移＝动效开销与「软」的观感；纸墨的「静」会淡一点，需要接受界面比现在「活」。
- **选它的信号**：你要的就是「现代化」这三个字；能接受界面有轻微动效与浮起层次。

---

### 丙 · 紧凑专业（小圆角 · 零阴影 · 快动效 · 高密度）

**一句话**：向 Obsidian / 专业工具靠——信息密度优先，线更清晰、动效近乎瞬时。

| 维度 | 参数 |
|---|---|
| 间距 | **2px 基准刻度** 2 / 4 / 6 / 8 / 12 / 16 / 24；页面 `20·26px`，控件 `4·10px`，卡片 `8·10px`，表格行 `5·9px` |
| 圆角 | 控件 **3** · 卡片 **4** · 弹窗 **6**；徽标也是小圆角，**不用胶囊** |
| 阴影 | **零阴影**（全部靠 1px 描边 + 色阶）；只弹窗一档硬阴影 `0 8px 24px rgba(0,0,0,.28)` |
| 动效 | **90ms** `ease-out`；只做颜色与透明度，无位移无缩放 |
| 图标 | Lucide/Tabler 线性，**14px / 1.5 描边**；纯单色，与文字同栏对齐 |
| 色彩层级 | **2 层表面** `bg / panel` + 描边层；线色对比度整体提高一档（现在 `--line: #e3ded4` 偏淡） |
| 字号 | UI 12 / 次要 11.5 / 页题 17 / 编辑器正文 15·17（不动） |

- **两主题适配**：零阴影在深色下天然成立（深色本来就靠描边）；需要单独调的是**深色线色对比**（现在 `--line: #3b382e` 在深底上偏弱，看板网格会糊）。
- **六套背景适配**：六套纹理照旧，但编辑器四周留白收窄（更满屏）；**深色下纹理压暗幅度需上调**——六套里偏浅的（素纸/宣纸/豆沙绿）在深色主题下会发白，需要更重的暗层。
- **代价**：字小、密度高，长时间写作偏硬；与「沉浸式写作」的柔软感方向相反；看板/画布/表格受益最大，正文编辑器受益最小。
- **选它的信号**：你更多时间花在构思看板、关系画布、伏笔/三线表格上；希望一屏能多看几行、少滚动。

## 四、三方向对照

| 问题 | 甲 · 纸墨精修 | 乙 · 现代通透 | 丙 · 紧凑专业 |
|---|---|---|---|
| 第一眼观感 | 更整齐，仍像原来 | **变化最明显** | 更「工具」，更快 |
| 圆角 | 4 / 6 / 8 | 8 / 10 / 14 | 3 / 4 / 6 |
| 卡片是否浮起 | 否（线 + 色阶） | 是（三档阴影） | 否（线 + 色阶） |
| 动效 | 120ms，仅颜色 | 180ms，含微位移/缩放 | 90ms，仅颜色 |
| 一屏信息量 | 中 | 少（间距最宽） | **多**（间距最紧） |
| 侧栏有图标 | 有 | 有（配 chip） | 有 |
| 深色适配复杂度 | 低（同构） | 中（阴影→表面提亮） | 中（线色/纹理压暗要调） |
| 编辑器纸感 | **最强** | 强（内描边防浮起） | 中（外围更满屏） |
| 与「优化、美化、现代化」的距离 | 中 | **最近** | 中（偏专业感） |

**代理倾向（可否决）**：若只选一个，倾向 **乙 · 现代通透**——你的原始诉求是「现代化」，而三方向里只有乙明确改变层次语言；同时它把编辑器处理成「纸面不浮起」，保住了写作面的纸感。若允许混搭，推荐 **乙的结构参数 + 甲在编辑器/纸面上的零阴影**（即：管理界面浮起，写作面安静）。混搭会多花一点施工时间，但两个诉求（现代 / 安静写作）都能拿到。

## 五、选定后的施工台账（供 #35）

无论选哪个方向，施工面是同一套（差别只在值）：

1. **新增 token 层**（`app/src/App.css` 顶部 `:root` 与 `[data-theme="dark"]` 内）：
   `--sp-1…--sp-8`（间距刻度）、`--r-ctl/--r-card/--r-dialog/--r-chip`（圆角）、`--sh-card/--sh-hover/--sh-dialog`（阴影）、`--dur/--dur-fast/--ease`（动效）、`--fs-ui/--fs-sub/--fs-title`（字号）。
2. **批量替换硬编码**：圆角 8 档 → 4 档；字号 17 档 → 5 档；间距归到刻度；阴影 8 处归到 3 档。引用处零结构改动（现有 229 处 `var()` 机制直接吃）。
3. **图标体系**：引入 `lucide-react`（ISC，tree-shakeable，React 组件，24px 网格、`strokeWidth` 可传参），统一 `size`/`strokeWidth` 常量；替换 `⚙ 设置`、`×`、`✓` 等字形；侧栏四项导航加图标（**不改导航结构，只加图形**）。新增依赖需在 #35 落地时一并记录。
4. **动效守卫**：所有 `transition/animation` 加 `@media (prefers-reduced-motion: reduce)` 关闭位移与缩放；动效只做颜色/透明度/阴影/变换，不用来传达信息。
5. **编辑器外观**：callout 卡片（#32）与内联图（#31）按选定方向的圆角/阴影/描边统一；六套背景在两主题下各过一遍。
6. **验收（#35 单上原有两条）**：两主题下所有页面视觉一致、无违和控件；编辑器内图片/卡片/正文风格统一。**补两条**：① 全站不再出现刻度外的圆角/时长硬编码（可用 grep 自查）；② 三方向参数表里的值能在 CSS 里逐条对上。
