# 社会关系画布（T13 / #70）

本规格取代旧「人物关系画布」中不可拖拽、坐标不落盘的约定，遵循 ADR 0008。入口为「人物与组织 → 画布」，与名单、组织档案共享同一批实体。旧项目继续使用原人物画布，作者通过「组织与归属」的预览和确认升级后启用统一社会画布；新项目也由该入口创建社会网，不静默升级。

## 数据与写入

唯一来源是 `构思/关系.yaml`。节点以「人物或组织＋名称」标识，圆形显示人物、圆角方形显示组织。节点名称和一句话身份／组织目的为可辨认摘要；详情展示权威档案的字段、正文和相关关系。档案编辑复用名单／组织卡的编辑器，保存后重新读取；画布不保存内容副本。

关系沿用起类、起、止类、止、类型、描述、秘密，并支持可选「方向: 有向|无向」逐条覆盖图例方向。没有覆盖时继承同名图例；图例外类型缺省有向。人物—人物、人物—组织、组织—组织均可连接，同对节点多条关系保留；自关系显示为环。组织成员关系的职位、任职等既有字段在画布编辑时保留。

「图例」按钮沿用原编辑框，编辑只改图例并保留条目未知字段、全部关系及布局。图例外类型显示提示；删除图例不删除关系。

布局采用类型化键，保存位置与固定状态，例如：

```yaml
布局:
  人物:阿风:
    x: 210.0
    y: 160.0
    固定: true
  组织:山门:
    x: 510.0
    y: 100.0
    固定: false
```

坐标是 SVG 画布坐标，范围 60～100000。缺位置的新节点按稳定次序补入空格点；已删除档案的布局和失效关系均保留，不自动清理。旧的不带类型布局键和所有未知字段原样保留。损坏的关系、类型化位置或逐条方向显式报错并拒绝覆盖。图例颜色与缺省样式复用旧画布规则；旧图例中未知方向仍按无向兼容，不改写原值。

每次写入携带载入时的关系文件内容指纹，外部变更时拒绝写入并提示刷新核对。只改当前操作的布局／一条关系，其他关系、图例、未知字段不动；保存走原子替换。社会升级日志尚存时全部写入停用。

## 交互

- 拖动节点，在松开时一次保存；点击切换多选，拖动不误切换选中。
- 固定／取消固定作用于所选节点。固定防止自动整理移动，仍可手工拖动。
- 「整理画布」只移动未固定的有效节点，避开固定和保留的位置；节点稳定排序、格点确定，无随机数，相同输入结果相同。
- 「全部重排」移动全部有效节点，保留固定标记。整个操作一次保存，并提供「撤销重排」恢复操作前所有位置及固定状态。
- 撤销保留到下一次位置／关系变更或刷新。刷新后重新读取磁盘位置；撤销本身也检查指纹，无法绕过外部修改。
- 方向键每次移动聚焦节点 20 个画布单位，Enter／空格切换选中；关系也可用键盘打开编辑。
- 节点可双击或按 F2 打开档案，详情提供编辑按钮；失效引用在详情和画布下方可见，并可由作者编辑。
- 人物多选保留提为矛盾、人物交汇、AI 梳理与人物对话入口；这些动作沿用原先人物材料边界。
- 窄屏时详情位于画布下方，画布内部滚动，不让整个页面横向溢出。所有表面与字体使用既有视觉 token，拖动不做额外动效。

## 验证

命令边界临时项目测试涵盖：同名异类身份、布局保存与重开、固定整理、稳定重复整理、整次重排与恢复、三种关系连接、方向与秘密、失效引用、未知字段、过期指纹、损坏数据、升级中断及旧项目显式升级。页面流程用模拟 IPC 验收拖动重开、固定整理、重排撤销、连边、人物与组织档案更新、键盘、1024px 窄屏与深色，以及保存失败回退。真实 Windows 原生窗口重启验收尚未执行。
