# 工笔（app）

个人网文创作工具：拆书积累 → 灵感沉淀 → 构思写作。设计文档见仓库根目录
[docs/设计共识.md](../docs/设计共识.md) 与 [ADR](../docs/adr/)。

技术栈：Tauri 2 + React + TypeScript + CodeMirror 6。

## 开发

```bash
npm install
npm run tauri dev    # 开发运行
cargo test           # Rust 侧单元测试（在 src-tauri/ 下）
npm run build        # 前端类型检查 + 构建
```

## 当前进度

1. **应用骨架 + 打开库文件夹**——三板块导航（拆书/构思/书写），
   拆书页可打开库文件夹并识别两种既有布局：根目录散文件、一书一文件夹；
   只读扫描，不搬动、不改写用户文件（ADR 0002）
2. **拆书编辑器**——书目点击进入 CodeMirror 6 编辑器；
   Ctrl+Enter / 「开下一章」按书级前缀模板续写（默认「第{n}章」，书级资料可配）；
   五插入块（点评、如果是我写、原文截图、出场人物、小结，Obsidian callout 格式）；
   粘贴图片自动存入附件并嵌入（一书一文件夹落 `附件/`，散文件落 `附件/<书名>/`）；
   书级资料（书名/成绩/简介/金手指/章前缀）懒生成同名 `.yaml`；
   Ctrl+S 保存，临时文件＋改名尽量原子（ADR 0002）
3. **书库首页**——按书浏览（含成绩等元数据）、全文搜索、桥段类型/解法跨书筛选；
   正文保存走版本指纹闸，冲突时重新加载或确认覆盖（ADR 0004）
4. **灵感库**——九类卡片＋未分类，一卡一文件存 `灵感库/<类别>/<标题>.md`；
   导入旧 `灵感.md`（按标签归类、杂项落未分类）；故事卡带「一句话核心」
5. **AI 侧边栏**——多供应商（OpenAI 兼容）流式对话、多会话历史、当前文档上下文；
   编辑器三命令（梳理/建议类型解法标注/提炼小结）给初稿，人确认后才落盘
6. **构思板块**（工单 #4 文件布局落地）——库根 `项目/《书名》/` 一书一项目：
   类型圈、矛盾池（可一键提为单元）、单元设计、排布（有序列表＋2:1/节奏体检）、
   人物、世界观、开头；`项目.yaml` 懒生成、未知键原样保留；
   按名引用失效只提示不自动改。正文编辑器属书写板块，待工单 #5 设计定稿
7. **故事卡转生单元草稿**（工单 #9）——灵感库故事卡一键选书转生：
   建 `构思/单元/<卡片标题>.md`（核心矛盾＝一句话核心、类型＝标签、正文给骨架），
   卡片「关联」记去向「《书名》/单元名」并可点击跳回项目的单元页；转生即断链、无同步
