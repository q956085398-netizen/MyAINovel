## What to build

主线里程碑可进入待打磨并在大纲页面顶部以完整便笺呈现；退出后仍属于原主线并保持人工叙事次序。同名里程碑和外部重排不能导致状态误写。

## Acceptance criteria

- [ ] 通过大纲页面完成里程碑进入、编辑、退出待打磨、保存与重读；状态保存在原 YAML 里程碑条目，不建立副本。
- [ ] 独立布尔键“待打磨”缺失或 false 为普通对象，true 为待打磨，退出移除键；旧主线文件无需迁移。
- [ ] 顶部便笺完整呈现已填标题、变化、读者感受、关联单元和备注，保留所属主线语境及原有有效操作；空区消失。
- [ ] 进出状态不改变高亮主线、所属主线、关联单元或人工次序，编辑与重开后仍保留状态及未知字段。
- [ ] 多条主线及同一主线里的同名里程碑可明确区分；不能仅以标题定位，也不能用陈旧数组索引修改外部重排后的另一条目。
- [ ] 定位无法唯一确认、表指纹陈旧或 YAML 损坏时拒写并要求重新载入，原文件完整；延续现有模型与指纹，不引入全库身份迁移。
- [ ] 状态操作保留目标未知字段、其他里程碑与主线的未知字段，遵循既有原子写与长活表冲突约定。
- [ ] 临时库与页面回归覆盖多主线、重复标题、外部重排、未知字段、损坏拒写、完整便笺及退出后次序恢复。
