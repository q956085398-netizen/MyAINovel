# 画板采用 JSON Canvas，人物关系以画板的边为唯一来源

拆书需要一张能随手画的板，构思的人物要在纸上分阵营、连线，旧模型却是三套各有规则的画布（人物关系、社会关系、地图语义），关系另存在 `关系.yaml`。决定：拆书画板与人物关系画板都存为 JSON Canvas 1.0（`.canvas`，Obsidian 原生可开），手绘笔迹放扩展字段；人物关系不再另存一张表，画板上的边就是关系本身（关系名、是否有秘密），阵营就是框。取代 ADR-0008 的社会网部分。

## Considered Options

- **关系表为主、画布只存坐标**（ADR-0008 的做法，取代）：两处要同步，画板上随手连的一条线还得回写成表里的一行，画和记被拆成两个动作。
- **自定义画布格式**（否决）：Obsidian 打不开，违背"随时可以回到 Obsidian"。

## Consequences

人—组织、组织—组织关系不再是一等数据；需要组织档案时在工具箱里打开。旧 `关系.yaml` 在迁移时转成画板的边（ADR-0011）。
