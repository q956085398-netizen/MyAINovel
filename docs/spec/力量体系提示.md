## 可删提示

新建可选择「带可删提示」或「从空白正文开始」。带提示只预填普通 Markdown 正文中的七个标题与问题：等级边界、力量来源、成长条件、代价限制、主角例外、剧情展示、下一阶段期待。标题、问题、回答和类别都可删除、留空或自由改写；仅词条名作为文件名必填。旧词条不会被补入模板。

技法在相应上下文的问题中出现，例如用具体事件展示力量、用代价产生矛盾、用尚够不到的目标形成期待；不新增理论板块、评分或缺项检查。
