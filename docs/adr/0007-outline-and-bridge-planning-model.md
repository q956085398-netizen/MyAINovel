# 大纲与桥段采用分层、单一来源的规划模型

长篇构思既需要自由书写的大局，也需要供可视化和书写提示读取的稳定结构。决定以 `构思/大纲.md` 承载立意与阶段构想、以 `构思/主线.yaml` 承载主线里程碑；桥段一律保存为 `构思/桥段/<名>.md` 的单一实体，未安排时在桥段库待命，安排进单元后只补关联与次序，不复制到单元文件。

## Considered Options

- **所有大纲都是自由 Markdown**（否决）：对人友好，却没有可靠的主线图数据来源。
- **所有大纲都是固定表单**（否决）：可视化稳定，却会在构思尚模糊时制造填写压力。
- **桥段直接嵌在单元正文**（取代）：无法保留尚未知道归属的本书桥段，也无法让书写页可靠地定位桥段意图。

## Consequences

主线图和单元内桥段次序都由人明确排序，关联单元或章节区间只辅助定位、不反向篡改叙事顺序。书写页只在计划存在时安静提示，未计划的章节仍可自由书写；AI 陪看必须由人主动发起，且只给反馈，不修改正文或评分。
