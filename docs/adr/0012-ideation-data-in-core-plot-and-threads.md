# 构思收成四页，数据合并为核心、剧情、线索三处

构思原有 14 个页签，数据也散在十来个文件里，打开构思先看到一张名词清单。决定：构思只有核心、人物、剧情、世界四页，埋下第一条伏笔后才出现第五页"线索"；数据跟着合并——类型圈、大纲、立意与主线的一句话进 `核心.md`；主线里程碑、单元次序与单元属性进 `剧情.yaml`；伏笔、期待、目标进 `线索.yaml`，以类别区分，状态机沿用原设计。取代 ADR-0007 的"大纲纸面 ＋ 主线文件"分层和 ADR-0008 的地图结构部分。

## Consequences

桥段仍是一桥段一文件的单一实体（ADR-0007 的这一条保留），但不再有游离于单元之外的桥段库：没想好归属的点子是矛盾池里的种子，桥段一起稿就属于某个单元。地图退为世界页的一种设定条目，带一个引导问题；地域、转场、三种地图法、时代与期待三线看板都作为工具箱视角，默认关闭。退役文件：`类型圈.md`、`大纲.md`、`主线.yaml`、`排布.yaml`、`地图结构.yaml`、`伏笔.yaml`、`三线.yaml`。
