# 书级四项上纸面：书档 callout＋拆书模板，废除 yaml 书级键

v1 把书名/成绩/简介/金手指放 yaml 侧车、经「书级资料」弹窗编辑——填了在纸面上看不见，弹窗交互还有"赶着填表"的压迫感（2026-09-13 用户访谈）。决定：四项以「书档」callout 块写在拆书稿顶部，纸面常驻、点击卡片即编辑；新建书的初始稿由库根 `拆书模板.md` 生成（`{书名}` 占位符替换）；yaml 里的四个书级键一次性迁进 md 后删除，桥段标注与未知键原样保留。代价：书库列表的成绩/金手指列改为从 md 书档的键名行解析（自由格式换约定键名）；章前缀移为全局设置，已自定义的书继续生效。这是「文件为唯一数据源」（ADR 0002）的延伸：结构化字段也尽量住在明文里。

## Consequences

`拆书.yaml` 退化为桥段标注的载体；AI 功能本就不读书级四项（已核实 ai_context 无引用），无连带改动。
