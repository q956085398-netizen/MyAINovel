# 个性化设置

> 工单 #17 决议（**grilling：三轮问答由用户逐项拍板**）。基线：ADR 0002（文件为唯一数据源——设置是软件装修，不进创作目录）、设计共识 §一（Windows 优先、界面全中文、纯个人使用）、#5 书写编辑器（编辑偏好先行例）。
> 定位：应用级个性化——主题（浅/深/跟随系统）、编辑器背景（内置纹理＋自定义图）、排版五项（字体/字号/行距/对齐/首行缩进，v2 扩，工单 #33）、自动保存间隔与章前缀缺省（v2，承载自 [拆书保存与模板.md](./拆书保存与模板.md)）。一个字都不进创作目录。

## 一、决议总览

| 问题 | 决议 |
|---|---|
| 主题 | **浅色｜深色｜跟随系统** 三态，管全局配色；管理页/侧栏/看板/对话框全跟、不铺底图 |
| 背景铺哪 | **只铺拆书/书写两个编辑器**；沉浸式（正文直接写在背景上），不做中央纸页 |
| 背景素材 | **内置六套纹理＋自定义本地图片**（记路径、不拷贝、不进创作目录） |
| 排版 | **字体（宋｜黑｜楷｜跟随系统）＋字号＋行距**，两个编辑器共用 |
| 设置存哪 | **应用状态（前端 localStorage）**，与库位置/书写偏好同一纪律 |
| 入口 | 侧栏底部齿轮「设置」；AI 供应商设置不并入（留在 AI 侧边栏） |

## 二、主题（浅｜深｜跟随系统）

- **机制**：现有 CSS 变量组（`--bg/--panel/--ink/--accent/--line/--sidebar-*` 等，App.css 约 229 处 `var()` 引用）按主题重定义——根元素挂主题属性，浅色＝现行变量值，深色＝整组翻深；引用处零改动。
- **跟随系统**＝监听系统深浅偏好；三态里显式选「跟随系统」才跟随，选浅/深则锁死手选。
- **深色模式覆盖**：CodeMirror 编辑器主题（正文颜色、语法高亮、伏笔/三线引文装饰）同步适配；AI 侧栏、全部对话框跟主题。
- 管理页面（书库/灵感库/构思各看板）只跟主题换色，**不铺背景**（见 §三的边界）。

## 三、编辑器背景

- **范围**：只拆书编辑器＋书写编辑器；其余界面一律不铺。
- **沉浸式**：背景即纸页，正文直接写在背景上，字色随主题适配（深色纹理配浅字）；不做「背景上再盖一张中央纸」的纸张式。
- **内置六套**：素纸（默认＝现行米白，等价于没开）、宣纸（细纹米黄）、羊皮（暖褐斑纹）、豆沙绿（经典护眼绿）、竹青（淡青灰）、暮山（深墨灰，深色模式的原生搭配）。
- **深色联动**：深色模式下浅色纹理自动叠压暗层（或直接选暮山）；自定义图片同样处理。
- **自定义图片**：软件里选图，**只记路径**存应用状态，不拷贝进创作目录——背景是装修不是数据（与「封面」的纪律相反，封面是书的数据、随库走）。按铺满裁切适配。

## 四、排版五项与工具栏（v2 扩，工单 #33）

- **正文字体**：宋｜黑｜楷｜跟随系统，四选一；**字号、行距**：滑选。
- **对齐**（v2 新增）：左｜中｜右｜两端，默认**两端对齐**；**首行缩进**（v2 新增）：默认 **2 字符**、可关。两项均为**视图层显示效果**（中文小说排版习惯），不改动 md 内容——写进文档的格式只有导出选项「段首缩进」。
- **两个编辑器共用**同一设置（`editorTheme.ts` 统一生效）；构思便签编辑器仍不跟随。
- **编辑器顶部工具栏**（v2 新增）：字体/字号/行距/对齐/首行缩进即时控件，与设置面板「排版」小节**同源同步**（同一存储键，两处任改一处全局生效）。
- 导出对话框「段首缩进」**默认勾选**（复制到发布渠道免逐段重排）。
- 与书写板块既有编辑偏好（打字机滚动/沉浸模式，`gongbi.writing.prefs`）**并存不合并**：那些是书写行为开关，这是排版。

## 五、设置面板

- **入口**：侧栏底部齿轮。
- **条目**（v2 后六项）：主题／编辑器背景／排版（五项＋工具栏同源）／**自动保存**（间隔档位 1/2/3/5/10 秒、默认 3 秒，拆书/书写共用，见 [拆书保存与模板.md](./拆书保存与模板.md) §二）／**拆书·章前缀**（全局缺省 `第{n}章`，见该 spec §六）／库位置。
- **库位置**：显示当前库路径＋「更改」（沿用打开库文件夹逻辑）＋「新建」（见 [书库新建与展示.md](./书库新建与展示.md) §三）。
- **持久化**：前端 localStorage（应用状态）；纯前端关注点，Rust 不参与。
- 不并入：AI 供应商设置（留在 AI 侧边栏 ProviderSettingsDialog）、每日目标（留在书写页）。

## 六、判死与复活信号

| 判死 | 复活信号 |
|---|---|
| 管理页/侧栏铺背景 | 真觉得书库首页太素 |
| 中央纸页式背景 | 沉浸式用久了仍觉得「纸感」不足 |
| 每项目/每编辑器各自的背景设置 | 真想拆书和书写用两套背景 |
| 背景图拷进创作目录 | 想把背景当素材随库带走 |
| AI 供应商设置并入设置面板 | 在设置里找供应商入口成了高频动作 |
| 内置纹理做成可安装扩展包 | 六套真用不够、且想换着来 |
| 排版写进 md 文档（富文本化） | 真要「所见即所得＝发布所得」 |
| 拆书/书写各自排版 | 真想两编辑器两种排版 |
