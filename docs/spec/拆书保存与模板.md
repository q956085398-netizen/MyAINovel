# 拆书保存与模板 · 书档

> 工单 #28/#29/#30 决议（2026-09-13 grill-with-docs 三轮访谈，用户逐项拍板）。基线：ADR 0002（文件为唯一数据源）、ADR 0004（写路径原子＋指纹对账）、ADR 0006（书级四项上纸面）、[书写编辑器.md](./书写编辑器.md)（保存网先例）、[拆书yaml-schema.md](./拆书yaml-schema.md)（yaml 由此收缩）、[书库新建与展示.md](./书库新建与展示.md) §二（新建书流程）。
> 起因：用户实际丢失整段拆书内容——拆书编辑器没有任何自动保存，「← 返回」的"确定丢弃"确认框一点，内存内容随组件卸载永久消失（磁盘上的 `拆书.md` 从新建起就是空的）。

## 一、决议总览

| 问题 | 决议 |
|---|---|
| 拆书自动保存 | 对齐书写编辑器保存网：停笔防抖自动存＋返回即存＋切板块/卸载/关窗兜底＋覆盖前快照 |
| 自动保存间隔 | 设置面板新增，档位 1/2/3/5/10 秒、默认 3 秒，拆书/书写两编辑器共用 |
| 拆书模板 | 库根 `拆书模板.md` 一份，用户在应用内自编辑；新建书套用，`{书名}` 替换 |
| 书级四项 | 废「书级资料」弹窗；四项以「书档」callout 块上纸面，点击卡片即编辑 |
| yaml 书级键 | 书名/成绩/简介/金手指四键一次性迁入 md 后删除；桥段标注、章前缀键、未知键原样保留 |
| 书库列表取数 | 成绩/金手指列改从 md 书档键名行解析；扫描只读不写盘 |
| 章前缀 | 全局设置（默认 `第{n}章`）；书 yaml 已有自定义值继续优先生效 |

## 二、拆书编辑器保存网

与书写编辑器（`docs/spec/书写编辑器.md` §3.1）逐项对齐，同一套实现收口、不另起炉灶：

- **停笔防抖自动存**：docChanged 重置计时，停笔满间隔（默认 3 秒）走既有保存链路——指纹对账、冲突裁决全部不变。
- **返回即存**：「← 返回」先保存成功再退回书库；保存遇冲突才弹既有冲突裁决框。**删除"有未保存的修改，返回将丢失，确定吗？"确认框**——返回永远不丢内容。
- **兜底存**：切出拆书板块（隐藏不卸载）即存；组件卸载即存；应用关窗走 Tauri 关窗事件（阻止默认→保存→再关）——关窗钩子做在应用级，拆书/书写两编辑器共用，书写侧顺带补齐。
- **覆盖前快照**：沿书写侧同款机制——`.gongbi/历史/`（点开头、Obsidian 与扫描天然忽略）、同内容跳过、最小间隔节流、份额度、失败不阻断保存；拆书快照落书内（散文件书落库根 `.gongbi/历史/<书名>/`）。

## 三、拆书模板

- **落点**：库根 `拆书模板.md` 一份；懒生成——首次点「拆书模板」入口或首次新建书时不存在则落默认模板。
- **默认模板**：

```markdown
> [!书档]
> 书名：{书名}
> 成绩：
> 简介：
> 金手指：

第1章
```

- **编辑入口**：书库页顶部「拆书模板」按钮 → 以拆书编辑器打开（同一编辑器、同一保存网），返回回书库。模板就是普通 md，OB 里也能改。
- **套用**：`create_book` 读模板 → `{书名}` 全文替换 → 写 `《书名》/拆书.md`；模板缺失或读失败**回退空文件**，不阻断新建。
- **边界**：只作用于新建，已有书不回填（想套手动复制）；占位符仅 `{书名}` 一个，其余 `{…}` 原样保留；插入块不可预设施加于每章（用户确认：有时十几章没有点评，块随需手插）。

## 四、书档

- **形态**：`> [!书档]` callout 块，长在稿顶（模板/迁移保证位置）；插入块家族第六员（工具栏可插，常规来自模板与迁移）。
- **键名行约定**：块内以 `书名：`/`成绩：`/`简介：`/`金手指：` 起始的行是**解析面**（书库列表取数），行内容自由；非键名行自由备注。约定换自由：改了键名，列表列就取不到——不校验、不报错。
- **编辑两条路等价**（文件是唯一源）：点卡片标题行 → 弹四项表单（沿用现 BookMetaDialog 的表单壳，保存写回 md 书档块、不碰 yaml）；或光标进块直接改文本。
- **渲染**：卡片化由 [编辑器渲染层.md](./编辑器渲染层.md) 承担（#32 先行）。
- **书名口径**：书库列表主名＝书档书名 > 文件夹名（散文件书＝文件名）兜底，与原 yaml 时代同规则。

## 五、迁移与 yaml 退役

- **触发**：打开书（编辑器加载）时一次性执行；**书库扫描绝不写盘**。
- **规则**：
  - md 无书档块且 yaml 有四键 → 四键非空值生成书档块插到稿顶，yaml 四键删除；
  - md 已有书档块 → yaml 四键直接删除、不搬值（md 为准）；
  - yaml 桥段列表、未知键、章前缀键**原样保留**（读-合-写纪律不变）。
- **列表列过渡**：未迁移的书（还没打开过）列表取数顺序＝md 书档 > yaml 残键 > 空——扫描只读也能显示。
- **懒生成语义更新**：yaml 首次落盘时机＝首次桥段标注（「书级资料」入口已废）。
- 散文件书同样适用（书档块插稿顶）。

## 六、章前缀全局设置

- 设置面板新增「章前缀」（默认 `第{n}章`），存应用状态。
- 开下一章取值顺序：书 yaml 已有自定义 `章前缀` 键 > 全局设置。新建书不再落章前缀键。

## 八、测试决策

- **接缝：Rust 命令/模块层单测**（沿 `book_file.rs`/`trope.rs`/`library.rs`/`chapter.rs` 既有先例）；前端手动验收＋tsc 构建门。
- cargo test 清单：
  - 模板：默认模板落盘；`{书名}` 替换（含多次出现）；模板缺失回退空文件；其余占位符原样。
  - 书档：键名行解析（含自由行、多块取首块）；块生成；散文件书插顶。
  - 迁移：四键非空搬值＋删键；md 已有书档只删键；空值不搬；桥段/未知键/章前缀键保留。
  - 快照：首次覆盖留档、同内容跳过、节流、失败不阻断（沿 `chapter.rs` 测试形状）。
  - 列表取数：md 书档优先、yaml 残键过渡、两者皆无显示空。
- 前端手动验收：写→不按保存→返回→重进内容在；间隔设置两编辑器生效；书档两路编辑等价；冲突裁决与指纹闸不回归。

## 九、判死与复活信号

| 判死 | 复活信号 |
|---|---|
| 多套命名模板（精拆/略拆） | 真拆出两套固定套路 |
| 占位符扩展（{日期} 等） | 模板里反复手写可自动填的内容 |
| 书档字段校验/必填 | 想按成绩排序筛选书库 |
| 迁移重跑开关 | 迁移结果不对需要重跑 |
| 拆书/书写各自间隔 | 真想两编辑器不同节奏 |
| 模板按书定制 | 不同书真要不同初始稿 |
